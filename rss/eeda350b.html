1. 你将得到什么

读完这一篇，你能拿走四样东西：

  1. 一张分组地图：12 个端点按用途分组，知道什么数据该敲哪个门；
  2. 一行取数的代码：主要端点一次返回，不用循环拼装；
  3. 北交所报表缺项与技术指标序列短的坑；
  4. 三个真实踩坑点，都是第一次用几乎一定会踩的。

代码全部自包含，复制进 .py 直接能跑，不依赖 numpy / pandas。

2. 本篇取数约定

  • 全部接口都是 GET + query 参数，token 放在查询串里（?token=xxx）；
  • 统一基址 https://api.zhituapi.com；
  • 代码块里的 你的token 是占位符，换成你的 token 即可；
  • 所有接口路径均取自官方已验证文档，跨篇零重复。

6. 坑与注意事项

坑 1：报表可能缺项。 北交所财务报表 /bj/fin/* 与沪深同源但可能缺项，取数前确认。

坑 2：序列短。 北交所技术指标 /bj/history/{macd,...} 序列短，参数范围要小。

坑 3：流动性低噪音大。 北交所流动性低，技术指标信号噪音大，别直接套沪深策略。
