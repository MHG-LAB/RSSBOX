    1、聚合函数（GROUP BY / OVER 子句可用）

    函数说明
    AVG(表达式)平均值，忽略NULL
    SUM(表达式)求和，忽略NULL
    MIN(表达式)最小值
    MAX(表达式)最大值
    COUNT(列)统计非NULL行数
    COUNT(*)统计总行数（含NULL）
    COUNT_BIG(*)返回bigint，适合超大表
    STDEV(表达式)样本标准差
    STDEVP(表达式)总体标准差
    VAR(表达式)样本方差
    VARP(表达式)总体方差
    GROUPING(列)判断是否为ROLLUP/CUBE聚合行
    GROUPING_ID(列1,列2)生成分组掩码，2008支持

    示例：

    SELECT SUM(amt),COUNT(*) FROM orders GROUP BY status;

    2、日期时间函数（SQL2008重点）

    datepart 取值：year,quarter,month,day,week,hour,minute,second,millisecond

    函数语法说明
    GETDATE()GETDATE()返回当前 datetime
    SYSDATETIME()SYSDATETIME()返回 datetime2(7) 高精度（2008新增）
    SYSDATETIMEOFFSET()SYSDATETIMEOFFSET()datetimeoffset 带时区偏移（2008新增）
    SYSUTCDATETIME()SYSUTCDATETIME()UTC时间 datetime2(7)
    DATEADDDATEADD(datepart,num,date)日期增减
    DATEDIFFDATEDIFF(datepart,start,end)间隔差
    DATEPARTDATEPART(datepart,date)返回整数
    DATENAMEDATENAME(datepart,date)返回名称字符串（如’星期一’）
    DAY() / MONTH() / YEAR()YEAR(date)简写，返回int
    ISDATE(字符串)ISDATE('2025-01-01')是否合法日期，1是0否
    TODATETIMEOFFSETTODATETIMEOFFSET(dt,offset)转为带时区datetimeoffset
    SWITCHOFFSETSWITCHOFFSET(dtoffset,offset)修改时区偏移

    示例：

    SELECT DATEADD(day,7,GETDATE())
SELECT DATEDIFF(day,'2026-01-01',GETDATE())

    3、字符串函数（SQL2008无TRIM，LTRIM/RTRIM组合）

    函数语法说明
    LEN(str)LEN('abc')字符长度，不含尾随空格
    DATALENGTH(str)DATALENGTH(N'中文')字节长度（nvarchar每个汉字2字节）
    LEFT(str,n)LEFT('abcd',2)左侧n字符
    RIGHT(str,n)RIGHT('abcd',2)右侧n字符
    SUBSTRING(str,start,len)SUBSTRING('abcd',2,2)截取
    LTRIM(str)LTRIM(' aa')去左空格
    RTRIM(str)RTRIM('aa ')去右空格
    CHARINDEX(pat,str[,start])CHARINDEX('bc','abcdbc')查找子串位置，0=找不到
    PATINDEX('%pat%',str)PATINDEX('%[0-9]%',str)支持通配符%_[]
    REPLACE(str,old,new)REPLACE('a-b','-','/')替换
    REVERSE(str)REVERSE('123')反转字符串
    UPPER(str) / LOWER(str)大小写转换
    STR(num[,len[,dec]])STR(123.45,6,1)数字转字符串
    ASCII(char)ASCII('A')返回字符ASCII码
    CHAR(int)CHAR(65)ASCII码转字符
    NCHAR(int)NCHAR(20013)Unicode码转字符
    UNICODE(str)UNICODE(N'中')返回Unicode编码

    2008 去首尾空格写法：LTRIM(RTRIM(@s)) 2008 没有 CONCAT，拼接用 a + b + c，注意NULL会让整体变NULL：ISNULL(a,'') + ISNULL(b,'')

    4、数学函数

    函数说明
    ABS(n)绝对值
    SIGN(n)正负：1/-1⁄0
    CEILING(n)向上取整
    FLOOR(n)向下取整
    ROUND(n,精度)四舍五入
    POWER(n,exp)幂运算
    SQRT(n)平方根
    SQUARE(n)平方
    RAND([seed])0~1随机浮点数；同seed固定序列
    PI()π常量
    EXP(n)e的n次方
    LOG(n)自然对数ln
    LOG10(n)以10为底对数
    SIN/COS/TAN/ASIN/ACOS/ATAN三角函数（弧度）
    RADIANS(deg) / DEGREES(rad)角度↔弧度转换
    SELECT RAND(CHECKSUM(NEWID())) -- 每行不同随机数，常用

    5、元数据函数（查库、表、列、对象ID/名称）

    函数说明
    DB_ID([dbname])数据库ID，不传则当前库
    DB_NAME([dbid])数据库名
    OBJECT_ID(objname[,type])对象ID（表/视图/存储过程）
    OBJECT_NAME(objid[,dbid])对象名称
    OBJECT_SCHEMA_NAME(objid[,dbid])对象架构名
    SCHEMA_NAME([schema_id])架构名
    SCHEMA_ID([schemaname])架构ID
    COL_NAME(table_id,col_id)列名
    COL_LENGTH(tab,col)列定义长度
    COLUMNPROPERTY(id,col,prop)列属性：IsIdentity、IsComputed
    OBJECTPROPERTY(id,prop)对象属性：IsTable、IsView、IsProcedure
    INDEXPROPERTY(objid,idxname,prop)索引属性
    TYPE_NAME(typeid)类型名称
    TYPE_ID(typename)类型ID

    示例：

    SELECT OBJECT_NAME(OBJECT_ID('dbo.orders'))

    6、安全&用户登录函数

    函数说明
    SUSER_SNAME([sid])Windows/SQL登录名
    SUSER_SID([login])登录SID
    USER_NAME([uid])数据库用户名称
    USER_ID([username])数据库用户ID
    CURRENT_USER当前数据库用户
    SYSTEM_USER当前登录账号
    SESSION_USER当前会话用户
    IS_MEMBER('角色')是否属于数据库角色，1/0/null
    IS_SRVROLEMEMBER('服务器角色',[login])是否服务器角色成员
    SELECT SYSTEM_USER, CURRENT_USER

    7、全局变量 @@ （配置/会话信息）

    变量含义
    @@VERSIONSQL完整版本信息
    @@SERVERNAME服务器实例名
    @@SERVICENAME服务名
    @@SPID当前会话SPID
    @@ERROR上一条语句错误号（⚠️立刻重置，优先TRY CATCH）
    @@ROWCOUNT上语句影响行数
    @@IDENTITY最后标识值（范围是会话全局，慎用，推荐SCOPE_IDENTITY()）
    SCOPE_IDENTITY()当前作用域最后IDENTITY，最推荐
    IDENT_CURRENT('表名')指定表最后IDENTITY，跨会话
    @@TRANCOUNT当前事务嵌套计数
    @@LANGID / @@LANGUAGE语言ID/名称
    @@DATEFIRST一周第一天（1=周一，7=周日）
    @@LOCK_TIMEOUT锁超时毫秒
    @@NESTLEVEL存储过程嵌套层级

    重点：新增标识取值优先：SCOPE_IDENTITY()

    8、转换、判断、逻辑函数

    函数说明
    CAST(表达式 AS 类型)类型转换
    CONVERT(类型,表达式[,style])带格式转换（日期格式化主力）
    ISNULL(表达式,替代值)为空替换，2参数
    COALESCE(v1,v2,v3...)返回第一个非NULL值，多参数（推荐优先COALESCE）
    NULLIF(a,b)a=b返回NULL，否则返回a
    CASE分支判断（2008支持简单CASE、搜索CASE）

    CONVERT日期style常用：

    • 101：mm/dd/yyyy
    • 120：yyyy-mm-dd hh:mi:ss（ODBC，最稳）
    SELECT CONVERT(varchar(20),GETDATE(),120)

    9、排名/窗口函数（SQL2008支持，非常常用）

    ⚠️ 2008支持OVER，但不支持RANGE、ROWS框架，只能PARTITION BY + ORDER BY

    函数说明
    ROW_NUMBER() OVER(PARTITION BY col ORDER BY col)连续唯一序号
    RANK() OVER(...)并列同号，序号跳号
    DENSE_RANK() OVER(...)并列同号，序号不跳
    NTILE(n) OVER(...)分成n组

    示例：

    SELECT *,ROW_NUMBER()OVER(PARTITION BY dept ORDER BY salary DESC) AS rn
FROM emp

    10、其他系统函数

    函数说明
    NEWID()生成uniqueidentifier GUID
    CHECKSUM(表达式)生成校验和，用于比较行
    BINARY_CHECKSUM二进制校验
    HASHBYTES('MD5','xx')哈希，支持MD5/SHA1（2008无SHA2_256）
    HOST_NAME()客户端主机名
    HOST_ID()客户端进程ID
    APP_NAME()当前连接应用程序名
    ISNUMERIC(表达式)是否可转为数字（坑：+、-、$也返回1）
    SELECT NEWID(), HOST_NAME(), APP_NAME()

    重要避坑清单（SQL2008专属）

    1. ❌ 没有 TRIM() → LTRIM(RTRIM())
    2. ❌ 没有 CONCAT() → ISNULL(a,'')+ISNULL(b,'')
    3. ❌ 没有 STRING_SPLIT、STRING_AGG
    4. ❌ 窗口OVER不能写 ROWS BETWEEN ...（2012才支持）
    5. ISNUMERIC 有坑，验证数字谨慎使用
    6. @@IDENTITY 触发器会串值，优先 SCOPE_IDENTITY()
    7. datetime 精度 3.33ms；datetime2精度更高，2008新增
