X/twitter 运营必用 Skill, 可以审查发帖, 也可以问问题

liyu7352:

前段时间研究了一轮 X / Twitter 的公开推荐代码，整理成了文章。后来发现，这些内容更适合做成一个可以随时提问的工具：碰到具体问题，直接查对应的代码和适用条件。

于是做了 For You Skills，给 Claude Code 、Codex 、Cursor 等支持 Skills 的工具使用。

项目：github.com/alexliyu7352/for-you-skills

如果你也在经营 X ，可能纠结过这些问题：

  • 今天已经发了一篇，另一篇要不要等到明天？
  • 一篇长文，应该发普通 Post 、Thread ，还是 Article ？
  • 网上说“第二篇曝光打六折”，这个说法到底从哪来的？
  • 草稿写好了，开头、长度和配图有什么具体问题？

这些都可以直接问它。

我比较在意的是回答的依据能不能查到。所以除了研究结论，也把对应的原始代码链接、适用条件和未解决的问题整理进了知识库。回答时会查相关条目，再给建议；公开证据不足的地方，也要说明白。

比如“第二篇打六折”这个案例，重点就是查清楚代码里的“第二篇”到底在数什么，以及分数倍率能不能直接理解成曝光比例。演示里保留了这次问答和对应源码，可以自己核对。

有草稿的话，也可以让它审稿。它会检查实际开头、统计长度、考虑首图和后续配图、判断内容更适合哪种发布形式，并给出具体修改。目前一共 8 个技能，通过一个总入口按问题选择工作流。

安装先用这一条：

npx skills add alexliyu7352/for-you-skills --skill x-assistant

装好后，可以在对应工具里试着问：

使用 x-assistant：我今天上午已经发了一篇 X 帖子，下午还有一篇不同主题的内容。该今天发还是明天发？请给建议，并说明相关源码支持什么、不能证明什么。

也说明一下边界：知识库基于特定版本的公开源码研究，不能据此确认全部线上配置，也不能保证涨粉或曝光。模型、联网和生图等能力由你使用的工具提供。

这里有 78 秒案例演示及完整记录，之前的 中文研究文章 也保留着。

想找一些本身就在用 AI 工具、也有 X 发帖需求的人试试。尤其欢迎拿你真正纠结过的问题，或者一篇准备发布的草稿来测试。

如果试了，最想听到的是：它有没有帮你做出一个具体决定？哪一段回答仍然空泛，或者证据对不上？
