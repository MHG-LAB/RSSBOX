1Password 确认内部系统遭入侵

11 月 25 日，密码管理服务提供商 1Password 发布安全公告，确认攻击者通过一名员工的企业 GitHub 账号入侵其内部系统，导致部分用户账户信息及内部源代码泄露。1Password 表示，用户的密码保险库及其中保存的内容均未受到影响。

1Password 于 11 月 19 日开始调查此次安全事件。攻击者利用被入侵的 GitHub 账号向后端服务植入恶意代码，获取了部分用户的姓名、电子邮箱地址、账户及用户 ID、账户创建及最后登录时间、公钥、安全远程密码（SRP）协议参数，以及部分账户邀请、配置和恢复链接中的令牌。此外，攻击者还窃取了私有代码仓库中的源代码，并获得了 CI/CD 系统的访问权限。

1Password 采用基于零知识架构的端到端加密机制。对于使用传统账户密码登录的用户，1Password 通过双密钥派生机制（Two-Secret Key Derivation，2SKD），将用户设置的账户密码与设备本地随机生成、具有 128 位熵的 Secret Key 相结合，派生用于保护保险库数据的加密密钥。保险库数据在用户设备上完成加密后才同步至服务器，而账户密码及 Secret Key 均不会上传至服务器。此外，1Password 采用安全远程密码（SRP）协议完成身份验证，无需向服务器传输上述两项凭据。因此，即使攻击者取得服务器访问权限乃至保险库的加密数据，在缺少相应解密密钥的情况下，仍难以破解保险库内容。

1Password 表示，此次事件中，用户的密码保险库、账户密码、Secret Key、账户恢复密钥、客户端及浏览器扩展均未受到影响，内部调查亦未发现用户账户遭接管的证据。用户无需修改账户密码，但应警惕冒充 1Password 的钓鱼邮件、短信、诈骗电话及非本人发起的账户恢复请求。

目前，1Password 已禁用受影响的 GitHub 账号，撤销被盗令牌及攻击者建立的访问权限，恢复受影响服务，并轮换或撤销所有可能泄露的内部凭据。作为预防措施，1Password 还将账户邀请及恢复邮件中的验证码由 6 位纯数字升级为 10 位字母与数字组合，并聘请独立网络安全专家验证其事件处置及补救措施。来源

索尼 WH-1000XM4C 无线降噪耳机国行正式发售

11 月 26 日，索尼 WH-1000XM4C 头戴式无线降噪耳机在中国大陆市场正式发售，售价 1799 元。该产品基于 2020 年推出的 WH-1000XM4 打造，在延续原有外观及可折叠结构的基础上，更新了无线连接规格、音质调校及均衡器功能，整机重约 253 g，提供黑色、铂金银及香芋紫三种配色。

降噪方面，WH-1000XM4C 延续 HD 降噪处理器 QN1 与双噪声传感器技术，左右耳罩各配备两颗麦克风，分别采集耳罩内外的环境噪声。

音频方面，该产品采用配备液晶高分子振膜的 40 mm 驱动单元，支持 SBC、AAC 和 LDAC 音频编解码器、DSEE Extreme 数字声音增强技术及 10 段均衡器调节。

连接及续航方面，WH-1000XM4C 支持蓝牙 6.0 及双设备多点连接，开启和关闭主动降噪时的连续音乐播放续航分别最长约为 27 小时和 34 小时。来源

微软公布 Windows Server 2028 功能清理计划

11 月 17 日，微软宣布 Windows Server 2028 进入公开预览，并在官方文档中列出多项旧版功能的移除与弃用计划。其中，用于集中管理和部署更新的 WSUS 服务器角色被列入移除清单。Windows Server 2025 等较早版本中的 WSUS 将继续按各自产品生命周期获得支持，并可用于管理包括 Windows Server 2028 在内的受支持系统更新。

其他计划移除的功能包括 SMB 1.0、WINS 服务器角色、DirectAccess、PPTP 和 L2TP 远程访问，以及 VBScript 和 WMIC 命令行工具。系统还将取消传统 BIOS 启动支持，要求必须使用 UEFI。.NET Framework 3.5 将不再作为系统内置可选组件提供，但仍可独立安装；Windows PowerShell 5.1 则被列为弃用，目前仍与预览版引入的 PowerShell 7 并存。

针对断网和高度受控环境的更新管理需求，微软表示将继续推进相关技术，并在后续分享进展。来源

铠侠官宣 GP2 系列固态硬盘

11 月 26 日，铠侠（Kioxia）宣布推出面向 AI 与高性能计算场景的 KIOXIA GP2 系列固态硬盘。该系列采用第三代 XL-FLASH 低延迟 NAND 闪存，针对 GPU 直接访问进行优化，在 512B 数据块大小下的随机读取性能超过 1800 万 IOPS，接近前代 GP1 系列的两倍。

GP2 系列基于 PCIe 6.0 和 NVMe 2.3 规范设计，预计顺序读取速度最高可达 28 GB/s，写入耐久度最高达 50 DWPD，支持直接液冷（DLC）。铠侠目前正考虑采用 EDSFF E1.S（9.5 mm）及 E3.S 外形规格。来源
