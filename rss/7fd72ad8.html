理解 JavaScript 对象、原型与包装类

前言 前面我们学习了作用域链、闭包、执行上下文。而对象、原型 prototype / __proto__、包装类就是建立在 JS 对象机制之上的核心知识点。很多人分不清显式原型和隐式原型，也搞不懂原始值为什么调用方法时 V8 会自动 new，本文顺着对象创建的逻辑，把数据类型、构造函数、原型查找、包装类串起来。

一、JS 数据类型

JS 里常说万物皆对象，这是通俗说法。当我们定义一个原始字面量值的时候，V8 并不会立刻执行 new，只有在访问它的属性 / 方法那一刻，才会自动执行 new 包装类生成临时对象。数据类型分为两大类：基本数据类型和引用数据类型。 基本数据类型：number、string、boolean、null、undefined、bigint、symbol 引用数据类型：object、array、function

基本类型的值本身不是对象；引用类型本质都是对象，可以自由挂载属性和方法。 示例：

let num = 10
let str = 'hello'
let obj = { name: '张三' }
let arr = [1,2,3]
function fn(){}

解读： num、str 属于原始值，定义的时候只是存原始值，没有 new；只有写 str.toUpperCase() 访问方法时，V8 才会自动 new；obj、arr、fn 属于引用类型对象。

二、构造函数，批量创建对象实例

想要批量生成结构相同的对象实例，最常用的方式就是构造函数。 构造函数就是可以被 new 调用的函数，JS 内置提供了 Object、Array 等原生构造函数。

function Person(name){
  this.name = name
}
const p1 = new Person('小明')
const p2 = new Person('小红')

执行流程： 通过 new 调用构造函数，生成一个全新的实例对象；实例和构造函数通过原型建立关联，多个实例可以复用原型上的方法。

三、prototype（显式原型）与 proto（隐式原型）

prototype：函数天生自带的属性，它本身是一个对象 __proto__：对象天生自带的属性，它本身是一个对象

核心等式：实例.p1.__proto__ === 构造函数.prototype** V8 引擎访问对象属性的查找规则：优先查找对象自身显式拥有的属性，如果找不到，顺着 __proto__ 去原型对象中查找。

Person.prototype.say = function(){
  console.log('你好')
}
p1.say()

分析：p1 自身没有 say 方法，顺着 p1.__proto__ 找到 Person.prototype 上的 say。

四、包装类

原始类型本身不能添加属性和方法，但是我们可以直接调用原始值身上的方法，这就是包装类的作用。 当我们使用字面量写一个原始值，定义阶段不会 new；只有访问它的属性或者方法时，V8 才会默认执行 new Xxx()，创建一个临时对象实例；操作完成之后，V8 会立刻做拆箱操作销毁这个临时对象。

let s = 'test'
s.age = 18
console.log(s.age) // undefined

分析：给 s.age 赋值，触发装箱，只是给临时生成的包装对象添加属性，赋值结束临时对象马上销毁；再次读取的时候，又会触发装箱，生成全新的临时对象，找不到这个属性，返回 undefined。

重点结果：赋值语句不会报错，看似添加成功，但是读取的时候拿不到我们添加的属性，最终结果为 undefined。

五、常见问题

是不是所有类型都有包装类？不是，null 和 undefined 没有包装类，直接调用方法会报错。 prototype 和 __proto__ 的区别？prototype 属于函数，用来给实例共享方法；__proto__ 属于对象，用来向上查找原型属性，是原型链的依托。 为什么给原始值添加属性不报错但读不到？装箱是访问属性 / 方法时才临时创建对象，属性加在临时对象上，临时对象销毁后数据丢失，再次访问又新建一个独立的临时包装对象。 怎么理解 JS 中 “万物皆是对象”？这句话并不是说原始值本身就是对象。引用类型（数组、函数、普通对象）天然就是对象；而 string、number、boolean、bigint、symbol 这些原始值，之所以也会被说成 “对象”，根源就是包装类机制：在读取方法时会自动装箱，临时变成包装实例对象，能够访问原型链上的方法，并且它们的包装实例原型链最终都追溯到 Object.prototype。null、undefined 是特例，没有包装对象，不属于对象。这句话是方便理解的通俗概括，不是严谨定义。

总结

JS 数据类型分为基本类型与引用类型；定义原始字面量时 V8 不会立刻 new，访问属性 / 方法才自动 new 包装类；构造函数配合 new 批量创建实例。 prototype 是函数的显式原型，__proto__ 是对象的隐式原型，实例的隐式原型等于构造函数的显式原型。 对象属性查找优先自身，找不到顺着 __proto__ 向上查找；包装类通过自动装箱拆箱，让原始值可以调用方法。给原始值添加属性不会报错，但属性保存在临时对象上，对象销毁后无法读取，访问结果是 undefined。 “万物皆是对象” 是通俗说法：引用类型本身就是对象；原始值本身不是对象，但因为有包装类，可以临时包装成对象，拥有访问原型方法的能力，所以口语里也把原始值归到 “万物皆对象” 里面，null 和 undefined 除外。
