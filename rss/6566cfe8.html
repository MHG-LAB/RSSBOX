App+1｜RetroSweeper Go：我把扫雷做成了复古游戏机的样子


TL;DR 太长不看版： 👉 点击这里前往下载，也可以在 App Store 搜索「RetroSweeper Go」。目前国区暂未上架，其他地区可以下载。

我特别喜欢玩扫雷，甚至已经把它当成了一种日常「冥想」工具。打开玩一会儿，把注意力放到棋盘和数字上，人就能静下心来。

在电脑上玩扫雷，无论是 Windows 上的经典扫雷，还是 macOS 上的复刻版本，都有许多不错的选择。但我一直没在手机上找到合适的 App：一方面是外观没有特别符合心意的，另一方面是操作方式。我总觉得用手指戳屏幕，没有用鼠标点起来有感觉。

不过，手机接个鼠标才能玩确实也不方便，所以我想，是不是可以加入虚拟手柄：用十字键移动，再按 A/B 键翻开格子、插旗。以前 Game Boy 不就是这样子玩的吗？

找了一圈没有找到类似的，我就自己做了一个，名字叫 RetroSweeper Go。规则还是熟悉的扫雷：翻开格子、看数字、标记地雷，再慢慢把安全的区域找出来。我给它配上了复古游戏机风格的界面和手柄，希望可以唤起你的一些回忆。

给扫雷换上三种游戏机风格

目前游戏有 Famicom、Game Boy 和 PlayStation 三种主题，配色的灵感来自原版游戏机的机身、屏幕和按键等设计元素。（By the way，虽然图里 Famicom 和 Game Boy 的 A/B 键看起来比较像，但它们其实是不同的红色！）

Famicom：取自红白机经典的枣红色与暖白色，数字的配色则从 Mario、Link、Kirby 等角色身上寻找灵感。这也是游戏默认的主题。

Game Boy：棋盘背景色来自早期 Game Boy 的绿色点阵液晶屏幕，再搭配浅绿色背景和偏紫红色的按键。

PlayStation：以初代 PlayStation 的灰色机身和 Memory Card 的灰蓝色调为灵感，虚拟手柄按钮则带上一点 PlayStation 标志性的彩色点缀。

其实还想做一些别的主题，不过我并不是很会设计，现在这 3 款也是在 AI 的帮助下调了很久才满意。后面我也会继续慢慢改进。

可以直接点，也可以用虚拟手柄

在手机上玩扫雷，最直接的方式当然是触屏：轻触翻开、长按插旗。当周围的地雷已经全部标记完毕，还可以双击数字格，通过 Chord 快速展开周边未标记的格子。为了防止误触，我设置了长按阈值；假如总是不小心炸雷，可以去设置中调整长按的判定时间。

虚拟手柄则是用十字键移动选中的格子，再通过 A/B 按钮翻开或插旗，这样手指不用一直在棋盘上移动换位。左右手负责不同的操作，也不太容易误触。

当然，手柄模式下也不用只靠十字键一格格地移动：可以直接点棋盘，快速把光标定位到想去的格子。如果移动棋盘后，光标落在当前可见范围之外，棋盘边缘会出现方向箭头，帮助你定位。A/B 键的上下位置也可以按自己的喜好调整。

因为虚拟手柄是我专门做的，所以我自己当然更喜欢这种方式。哒哒哒地按下去，一格一格地推理，很容易进入心流。两种操作的感觉还是挺不一样，大家也可以都试试看。

依旧是熟悉的 3 种难度

游戏提供初级、中级和高级三种难度，棋盘大小和地雷数量都是标准配置。（目前还没有做自定义棋盘，因为我还没想好怎么做。）

棋盘支持缩放和移动，触屏模式下，棋盘下方还有 Minimap，方便查看整体进度和当前所在的区域。

我的习惯是，用触屏操作时，把棋盘放大一点，格子更大，手指会更好操作；使用虚拟手柄时，适当缩小棋盘，这样移动起来更快捷。

卡住的时候，不妨借一点道具

如果刚开始玩扫雷，还不太会判断数字之间的关系，找不到下一步怎么做，这时可以使用 Hint。游戏会帮忙翻开一个安全格，或标记一个能够判断出的地雷，并尽量优先提示当前操作位置附近的格子，不会动不动就帮你展开一个隔了十万八千里的格子。

当然，踩雷也是扫雷的一部分。失败后可以看看地雷究竟分布在哪里，也可以使用 Rewind 悔棋卡，回到上一步继续玩。

通关后可以查看自己的用时，也支持 Game Center 全球排行榜。不过，使用道具后的成绩会归入「辅助模式」，和常规成绩区分。

不会玩扫雷，就从教程开始

如果以前没玩过扫雷，游戏里也有互动教程，可以在实际棋盘上学习扫雷的基本玩法。

免费玩，或者一次买断升级

RetroSweeper Go 可以免费下载，支持离线游玩，每天也会赠送基础的 Hint 和 Rewind 道具额度。已经会玩的话，完全可以不用道具，按自己的节奏推理、通关。

PRO 是一次性买断，无需订阅，包含这些功能：

移除广告：免费版只有主动选择才会播放激励视频，用来获取一些道具，广告不会在游玩中自动弹出。PRO 则无需看广告。

解锁全部主题，并可无限使用 Hint 与 Rewind。使用道具后的成绩会进入辅助模式排行榜，和常规排行榜区分，因此不用担心道具影响排行榜的公平性。

No-Guess Mode：尽量生成可以通过逻辑推导解开的棋盘，减少最后只能二选一「猜雷」的情况。目前仍是 Beta 功能，不能保证每局都完全不需要猜测，算法也会持续优化。

具体价格以所在地区的 App Store 显示为准。
