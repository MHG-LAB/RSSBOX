Arch 系用 Greetd 实现开机自动进 Plasma Wayland，注销自动回桌面

适用场景

无人值守主机、串流主机、单用户机器。目标是：开机自动进桌面，注销后自动重新进入，不依赖 SDDM / PLM，避免 KDE 登录管理器的耦合和卡死问题。

前置条件

  • Arch 系系统，已安装 KDE Plasma Wayland
  • 已确认 startplasma-wayland 可用（which startplasma-wayland）
  • 当前使用的是 SDDM 或 PLM

1. 安装 greetd

sudo pacman -S greetd

2. 编辑配置

sudo nano /etc/greetd/config.toml

把文件内容替换为：

[terminal]
vt = 1


[default_session]
command = “startplasma-wayland”
user = “你的用户名”

必须修改的地方：

  • user = "你的用户名" → 改成你真实的用户名，例如 user = "zhangsan"
  • 其他内容不要保留默认值（agreety、greeter 用户等全部去掉）

保存：Ctrl+O 回车，Ctrl+X 退出。

3. 切换登录管理器

sudo systemctl disable --now sddm plasmalogin 2>/dev/null
sudo systemctl enable --now greetd

4. 重启验证

sudo reboot

重启后应直接进入 Plasma 桌面。在桌面终端里验证：

# 检查会话类型
loginctl show-session $(loginctl | awk 'NR==2{print $1}') -p Type


# 检查用户服务总线
systemctl –user status >/dev/null && echo user-bus-ok

注销一次，应自动重新进入桌面，不会停在登录界面。
