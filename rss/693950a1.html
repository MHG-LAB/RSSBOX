怀旧手记｜iPhone初代：乔布斯眼中理想的手机是怎么样的？


这一天，我已经期待了两年半。——史蒂夫·乔布斯

初代iPhone的发布

2007年1月9日，在旧金山举行的Macworld Expo大会上，时任CEO史蒂夫·乔布斯首先宣布了一则重要消息：

将用了30年的公司名「苹果电脑公司（Apple Computer, Inc.）」更名为「苹果公司」（Apple Inc.），去掉「电脑」一词。

而推动这一举措最直接的原因，就是同一天苹果将要发布一个全新的、颠覆性的产品：iPhone。

在大会上，乔布斯介绍完了其它产品后，缓缓说道：「过去两年半，我一直期盼着今天的到来。」

随后他先回顾了1984年的Macintosh和2001年的iPod，称它们都「改变了一切。」

接着，乔布斯宣布将发布三款革命性产品：「大屏幕触控的iPod」、「革命性手机」和「突破性上网设备」。

他反复强调「iPod、手机、上网」，并暗示众人这不是三台设备，而是一台设备。当现场气氛达到顶点时，乔布斯说出：「我们将其命名为：iPhone！」

首先，乔布斯重点展示的就是初代iPhone的3.5英寸电容式触控屏。同时对比了同期的全键盘手机：

  • 摩托罗拉 Moto Q：当时主打轻薄设计的 Windows Mobile 全键盘手机
  • Palm Treo：当时 QWERTY 全键盘手机的标杆之一
  • 诺基亚 E62：诺基亚在商务手机领域的全键盘代表机型
  • 黑莓 (BlackBerry)：当时全键盘手机的代表1

乔布斯将这些手机的照片并列展示，并指出了它们的共同「问题」：为了容纳固定的物理键盘，屏幕空间被严重压缩。他对此的评论是：「不管你需要与否，它们都得带着这些键盘。」

随后，他提出iPhone的解决方案：「我们要做的就是去掉所有按键，只做一块巨大的屏幕。」

同时，乔布斯当着众人将拿在手中的初代iPhone轻轻点亮，随即屏幕上出现经典的小丑鱼壁纸，下方的提示则写着「移动滑块来解锁」。当乔布斯将手指放在滑块上，轻轻的一划，iPhone的主页面就呈现出来了。

作为初代iPhone，乔布斯当时称其系统为OS X，并称其基于OS X（后来才正式命名为iPhone OS）。

当年台上的演示惊艳了世界，而十几年后，这台改变时代的机器也终于辗转来到了我手里。现如今我终于有机会收到一台初代iPhone，并与你一同分享乔布斯眼中理想的手机是怎么样的。

外观

息屏状态下iPhone正面非常简洁。正面能看到的是：前置听筒、3.5英寸电容式触摸屏、Home键。

而来到背面，初代iPhone采用拼接设计：上半部分为银色铝合金，下半部分为黑色塑料。虽然当时并没有Unibody机身这种概念，但是在初代iPhone上，后盖与边框的过渡也显得较为舒适。

在机身侧面，你能看到经典的静音拨钮、以及音量键。

上方则是开关机键、SIM卡槽和3.5mm耳机接口，下方有扬声器和当时iPod播放器同款的30针Dock接口。

回到手机正面，当我们按下Home键，屏幕便会亮起。我这一台的系统虽然已经升级到iPhone OS 3，但是经典的「移动滑块来解锁」等元素依旧存在。

按照提示手指轻轻从左向右一滑，就可以进入到iPhone的主页面。

系统

初代iPhone可以升级的最高系统版本为iPhone OS 3.1.3。我这台就是3.1.3，同时越狱安装了Cydia商店。

要说iPhone OS 3相较于iPhone OS 1有哪些升级，我认为最明显和实用的便是剪切、复制与粘贴，终于支持在应用内或跨应用移动文本和图片，是用户最期待的功能之一。

同时iPhone OS 3还有其他几项较为明显的升级点：

  • Spotlight 全局搜索：在主屏幕向右滑即可进入，可搜索联系人、邮件、日历、备忘录和iPod内容
  • 横向键盘：邮件、短信和备忘录等应用开始支持横屏输入，打字更方便
  • 语音控制：支持语音拨号和控制音乐播放2
  • 推送通知：第三方应用可通过弹窗、声音或角标提醒用户，弥补了当时无多任务后台的不足
  • 辅助功能：加入了屏幕阅读器（VoiceOver）等辅助功能3

虽然语音控制和辅助功能在初代iPhone上并不能体验，但iPhone OS 3在这台初代iPhone上的表现意外地不错。APP打开时的基础动画，以及系统整体的运行都较为流畅。

而且，当时网络上还有适用于iPhone OS 3的越狱工具，这为我们后期测试这台iPhone省去了很多不必要的麻烦。

软件

先说说系统自带的iPod应用。在iPhone OS 3上，它就叫iPod，图标是经典的橙色底加白色剪影。原因很简单：2007年，iPod是当时苹果最核心、最具代表性的产品线之一，iPhone上的音乐功能本质就是把这台iPod塞进了手机。叫iPod，是为了向消费者展示在iPhone上你也能用「iPod」听音乐。

我把提前准备好的音乐通过iTunes同步到了iPhone上。

打开iPod应用，底部是播放列表、艺术家、专辑、歌曲几个标签；但真正有意思的是把手机横过来。

横屏之后，屏幕会自动切到Cover Flow界面。专辑封面像一张张唱片一样从屏幕中间翻转过去，立体的UI让第一次上手的人几乎没有门槛。

比较可惜的是我在同步音乐的时候忘记给这些音乐文件手动添加封面，导致在iPhone上的Cover Flow界面无法显示音乐封面。不过，我在网上搜索到了一些Cover Flow界面的截图，一起来看看。

在iPhone OS 3上，iPod应用还支持Genius播放列表、播客和有声书。这些功能后来被Apple Music和播客应用取代了，但当年这个叫iPod的应用，本身就是「iPhone首先是一台iPod」最好的证明。

App Store从iPhone OS 2开始便已经上线，但现如今这台初代iPhone上的App Store已经无法正常访问。

所以想在这台初代iPhone上安装应用，就要用到ipa格式的安装包。不过无论是安装个人正版还是越狱版的APP安装包，我都推荐在越狱之后使用Cydia先安装AppSync 3.1插件。

安装完插件之后，就可以用电脑通过爱思助手等软件，把下载好的ipa安装包同步到iPhone上。同步时也要留意安装包支持的系统版本是不是iPhone OS 3：版本更高无法安装，太低也可能出现不兼容。

我前后一共安装了20多款软件和游戏，这里分享一些我简单体验的软件：

  • PDF Expert，一款PDF文件阅读器。软件本身很简洁，在3.5英寸屏幕上读PDF，字和图小是躲不掉的。但两根手指一捏一放，就能像在图库里预览图片那样，把PDF的细节放大看清楚。
  • 金山词霸，早些年iPhone OS（iOS）上很好用的翻译软件。内置了一些基础的单词，可以离线进行简单翻译。同时提供场景对话学习，还有记事本可以记录一些单词和句子。
  • 金山电池医生，就像软件名字一样，你可以在软件中看到目前手机大约剩余的电量。同时还提供参考项目，比如：剩余电量通过WiFi上网还可以进行多少小时。充电的时候，将软件打开，它可以记录充电所需的时间以及次数。（不过我并不觉得软件本身可以养护电池……）

游戏

iPhone OS 3上面已经有很多经典的游戏。配合这块电容式触摸屏，游戏的操控和体验感确实比同时期很多全键盘手机要更好。

比如说狂野飙车系列，我安装了4和5——当年少有的移动端3A赛车大作。这两款在初代iPhone上跑得很流畅，配合3.5英寸触控屏，玩起来更沉浸。和诺基亚按键机上的版本比，最明显的变化就是我不用一边看着画面操控赛车，一边还惦记手指有没有按对键。

当然，相比赛车游戏，相信大家更熟悉的肯定还是这几款：神庙逃亡、水果忍者，还有植物大战僵尸。

它们都有一个共同点：都是围绕着iPhone这种纯触控屏幕来设计交互逻辑的。在游戏操作上，神庙逃亡和水果忍者对第一次接触的人非常友好，几乎没有上手成本，你需要做的就是跟着画面上下或左右滑动。

而我个人最喜欢的还要属《生化危机》，这是卡普空（Capcom）发行、Ideaworks 3D开发的移植版。也是2008年CG电影《生化危机：恶化》的官方游戏版，剧情可以看作是对电影的补充和延伸。

游戏的故事发生在《生化危机2》「浣熊市事件」7年后，也就是《生化危机4》之后。主角是里昂·S·肯尼迪和克莱尔·雷德菲尔德，他们在哈佛维尔机场遭遇了新的T病毒爆发。

虽然游戏的操作逻辑有一定上手门槛，但熟悉之后，相信你会和我一样沉浸在游戏剧情里。

发布会的幕后

在简单上手体验了一番初代iPhone之后，我的感受是：如果放在当下，我一定会觉得智能手机本来就该是这样。

但是时间回到2007年的Macworld Expo大会上，当时的状况却截然不同：在那一场被视为「改变世界」的发布会，背后却是一场充满技术漏洞、临时补救和巨大心理压力的「高风险表演」。

更多幕后细节由当时参与项目的苹果前工程师安迪·格里尼翁（Andy Grignon） 在2013年对外披露：

幕后团队设计的一条「黄金路径」：因为当时的iPhone原型机极不稳定，「会随机掉线、失去网络连接、死机甚至直接关机」。软件同样问题重重：先发邮件再上网是正常的，但如果顺序反过来，手机就可能崩溃。为此，团队经过大量试错，设计出了一套必须严格遵守的特定操作顺序和方式，目的只是让手机在台上「看起来像是能正常工作」。

台上的多台备用机：初代iPhone只有128MB内存，多任务运行极易耗尽资源导致重启。但是乔布斯坚持现场演示所有重要功能，当时的解决方案就是在台上准备多台一模一样的iPhone。当一台手机内存不足或需要重启时，他会在观众不易察觉的情况下悄悄换用另一台。

被「固定」的信号强度显示：iPhone在初期的无线电系统很不成熟，信号容易中断重连。工程师在获得乔布斯同意后，修改了演示机的代码，使乔布斯手中的iPhone信号强度显示永远满格，无论真实信号如何。安迪·格里尼翁解释说：「如果无线网络真的发生故障必须重启，我们不希望被观众发现。」

专属的临时基站：为了保证演示时网络稳定，合作运营商 AT&T 特地在发布会现场搭建了一座便携式手机信号塔，这个信号塔只为台上演示的iPhone提供接入服务，以避免被现场数千名记者和观众的设备占用带宽。

这些幕后细节，当年的观众并不知晓。因为在2007年，人们看着台上乔布斯手中那块会发光的屏幕，对此的激动或许早就淹没了这一切。

主流厂商对iPhone的看法

不过，当时主流的厂商并不看好苹果推出的初代iPhone。主要原因之一是iPhone「离经叛道」的设计：没有实体键盘、不能换电池、售价高昂，且当时仅支持2G网络。这完全违背了当时由诺基亚、黑莓等巨头定义的手机「常识」。

从当时最具代表性的行业人物的言论里，我们可以了解一二：

微软 CEO 史蒂夫·鲍尔默：在接受采访时称iPhone是「世界上最贵的手机」，并断言它「没有机会获得可观的市场份额」，因为它没有键盘，无法吸引商务用户。

Palm CEO 埃德·科利根：评价称，苹果想进入手机市场，而Palm已经「苦苦挣扎了好几年才学会如何做一部像样的手机」。同时，Palm 高管层也认为 iPhone 基本上只是一个「娱乐装置」。

黑莓联席 CEO 迈克·拉扎里迪斯（Mike Lazaridis）：在接受采访时评价称，苹果在企业市场的存在感「微乎其微」，他同样不认为有人会想要一部没有实体键盘的手机。

但是我认为，新鲜事物和产品，总是要接受市场和消费者的检验。当越来越多的手机厂商推出触屏手机的时候，市场已经验证了乔布斯眼中理想的手机。iPhone是当今乃至未来智能手机的标杆之一。
