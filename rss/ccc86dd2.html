自带 Key、离线能打 Rime 码表：我写了一款开源 Android 输入法 TypeFree


在 Android 生态里挑选主力输入法，很多效率用户都会遇到一个割裂的现状：

一边是开源的 Rime 系输入法（如 Trime、Fcitx5-Android），本地离线、零广告、词库与码表高度可定制，但缺乏现代大模型的流式语音净写和上下文辅助能力；另一边是这两年涌现的商业 AI 键盘，语音转写和润色体验顺畅，却往往伴随着按月订阅费用、数据经由厂商云端中转，以及对九键、双拼、五笔、音形码表等中文高效方案的缺失。

为了解决自己日常打字与语音输入之间的割裂，我用 Kotlin 2.0 + Jetpack Compose + Material 3 + 原生 C++ librime 1.17.0（含 librime-lua） 开发了一款开源 Android 输入法 TypeFree，按 GPL-3.0 协议完整开源。目前版本已更新至 v3.8.0，官网 https://typefree.xuezhao.space/ 上也整理了 15 段真机录屏演示。

先说结论：它适合谁，不适合谁？

在展开细节前，先把定位和门槛摊开，方便判断它是否匹配你的需求：

  • 适合尝试的人：
    • 希望日常离线打字干净无广告，且有全拼、九键、小鹤双拼、五笔、星空键道或自定义 Rime 码表需求的 Android 用户；
    • 自己手里已有 Gemini、DeepSeek、阿里云百炼、豆包或局域网 Ollama 等 API，不愿再为输入法单独付一份 AI 月费订阅；
    • 经常在手机上使用语音输入、需要自动去口头禅与改口整理，或在微信等聊天软件里希望快速获得回复灵感。
  • 可能不太适合的人：
    • 希望完全“开箱免配置”、不想花 2 分钟申请或填写任何 API Key 就使用全部 AI 功能的用户（当然，不填 Key 时它可以作为纯离线 Rime 输入法使用）；
    • 正在使用 iOS 的用户（公开开源仓库目前仅维护 Android 8.0+ 版本）。

核心工作流一：语音净写与实时翻译

很多人放弃手机语音输入，并不是因为语音识别准确率低，而是自然口语里夹杂了大量停顿、重复和中途改口——例如说出“明天下午四点……哦不对，改成四点半开会，我提前把方案发群里”，传统语音转文字会原样输出，反而增加了二次编辑成本。

TypeFree 将语音输入默认做成「净写」流程：

  • 自动去噪与改口定稿：按住说话、松手提交后，直接过滤语气词并按最终意图输出带标点的书面语；
  • 语音直译上屏：支持中文口述直接转为英文或日文上屏，适合回复跨语言消息或填写英文表单；
  • 低延迟模型直连：在网络正常且选用轻量高速模型时，短句从松手到上屏通常在 0.3s 左右。

核心工作流二：Jev 聊天军师与键盘内嵌 AI 工具箱

在社交或职场沟通中，常会遇到“知道对方有潜台词、但一时想不好措辞”的场景。TypeFree 在键盘顶栏内置了两个互补的 AI 模块：

1. Jev 聊天回复助手

点击顶栏「军师」后，输入法会基于 Android 无障碍服务读取当前聊天页面的近期对话上下文，结合用户预设的关系类型（如伴侣、职场/HR、普通社交），在键盘面板中并行给出多套不同倾向的参考回复，并附带简短的策略说明。

在实际使用中，它支持连续多轮跟进（官网保留了恋爱反话拆解与 HR 谈薪各 4 轮完整真机实录）。为了避免自动化误操作，交互上做了两项克制的设计：

  • 仅置入、不代发：点击建议卡片只会把文本填入输入框，用户仍可自由删改后再手动发送；
  • 按需触发：不点击按钮不会在后台轮询屏幕内容。

2. 键盘内嵌工具箱（帮写 / 随手查 / 选中改写）

不需要跳出当前 App 来回复制粘贴，在键盘面板内即可完成：

  • 纯净帮写：输入零散关键词，在当前输入框直接起草成段文字；
  • 随手查：就地提问检索事实或命令，看完收起不打断当前页面；
  • 选中改写：在输入框选中已有句子，一键调整为更正式、精简或缓和的表达；
  • 节点测速：设置页内置多服务商接口延迟测试，方便对比不同模型与线路的真实首字响应时间。

核心工作流三：原生 librime 1.17.0 离线打字引擎

作为每天高频打开的基础工具，TypeFree 在 v3.8.0 把离线打字体验补到了接近完整主力键盘的水准：

  • 全拼、原生 T9 九键与小鹤双拼开箱即用：内置开源雾凇拼音词库，v3.8.0 新增基于 librime 的原生九键拼音（t9.schema.yaml），不额外增加词库体积；输入时顶部胶囊显示可读拼音切分，左侧竖列自动切换为合法拼音音节筛选栏，支持点击锁定与自然回退，切英文或密码框自动切换至 26 键。
  • 多码表与自定义方案管理：词库管理页支持一键安装开源五笔 86 与星空键道 6，同时兼容导入用户的自定义 Rime 明文方案或预编译 .table.bin 挂接包（例如小鹤音形、虎码），并加入了预编译码表防误删与自愈保护机制。
  • 面向形码/双拼用户的细节：支持四码 5 键宽次选底排、空码 26 槽自然延续探测、o* 快捷指令（日期、时间、反查、简繁切换）以及 L1 + L2 本地即时造词。
  • 26 键三向手势与实用小工具：每个字母键解耦点击、上滑、长按三种动作，支持逐键自定义及三档键帽角标显示（上滑角标 / 长按角标 / 隐藏角标）；同时内置输入框算式提示（如输入 125*8= 自动给出计算结果芯片）、200 条智能剪贴板（支持取件码提取与大爆炸拆词），以及系统大字号下的键盘 fontScale 独立防扭曲锁定。

BYOK 配置方式与隐私边界说明

TypeFree 坚持 BYOK（Bring Your Own Key） 与本地优先架构，这意味着：

  1. 零中转服务器：所有 AI 请求均由你的手机直接发往你在设置中填写的模型厂商端点（支持 Gemini、DeepSeek、阿里云百炼、豆包以及局域网 Ollama），不经过开发者服务器。
  2. 国内网络友好：仓库 docs/ 目录下提供了国内 API 与 DeepSeek 的配置图文指南，通常 2 分钟内即可完成配置；若只使用离线打字功能，无需填写任何 Key，可全程断网使用。
  3. 权限与脱敏透明：
    • 仅使用离线打字：无需授予麦克风和无障碍权限；
    • 使用语音净写：需要麦克风权限；
    • 使用 Jev 聊天读屏：需要手动授予 Android 无障碍权限，发往模型前会在端侧先对手机号、身份证号、银行卡等常见敏感字段做本地隐私脱敏。

获取方式与开源地址

TypeFree 遵循 GPL-3.0 协议完整开源，无广告与隐私埋点，兼容 Android 8.0 及以上设备（SDK 26～35）：

  • 项目官网（含 15 段真机演示与功能说明）：https://typefree.xuezhao.space/
  • GitHub 开源仓库：https://github.com/dengxuezhao/TypeFree
  • 最新版 APK 下载（v3.8.0）：https://github.com/dengxuezhao/TypeFree/releases/latest
  • 国内 API / DeepSeek 配置文档：仓库内 docs/domestic-api-setup-guide.md

目前项目由我个人利用业余时间维护，不同 Android 厂商 ROM 在无障碍保活与键盘高度适配上难免存在细微差异，欢迎大家在实际体验后通过 GitHub Issues 提交反馈或建议。
