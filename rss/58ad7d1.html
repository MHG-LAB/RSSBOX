插件+1：MiaoMint —— 类 RayCast 的标签管理工具


这是一份迟来的插件介绍，第一版在 2025 年 12 月份上架 Chrome 插件商店，在周刊和公众号中也多次提到过。

现在正式介绍一下我的第一个 VibeCoding 产物：MiaoMint —— 一个类 RayCast 的标签管理工具。

Chrome 商店页：MiaoMint - 智能标签页管理与命令面板

官方介绍页：https://miaomint.konata9.cc/

为什么是 MiaoMint？

Chrome 上标签管理的插件有许多，比如 OneTab、Tabme 等，我通常不会打开超过 10 个标签页，因此很少会用到这类工具。直到有一天我从 Zen 换回了 Chrome。

Zen 的 Panel 非常好用，Cmd + T 就可以在输入框内打开、切换标签页、访问网站等功能。 

可惜，Chrome 上并没有类似的插件。现在，我有了一个念头又有了 AI，为什么不自己造一个插件呢？

MiaoMint 名字是怎么来的？

众所周知，命名是软件开发的一大难题。好在现在有了 AI，我把猫咪元素 + 类 RayCast 的标签管理告诉 DeepSeek 后，从一众名称中挑选了这个。

MiaoMint - “Miao”（猫叫）+ “Mint”（管理、清新之意），听起来清新现代，适合未来扩展为多功能效率工具。

再用即梦做了一个 Logo。（AI 真是太好用了）

MiaoMint 的功能介绍

通过 Alt/Opt + M 的快捷键就可以在网页上打开插件。默认进入的是标签页列表，通过 /b, /h 等指令进行不同功能的切换。这里参考了 Vim 的命令方式，可以尽可能地在键盘上进行操作。

1. 标签页管理

默认插件打开就是标签页的管理，会列出当前打开的所有标签页（支持跨窗口）。列表一组为 9 个，通过上下方向键进行选择选择、左右方向键翻页。

选中后按下回车就能切换到对应的标签页；按下 Ctrl + w 可以关闭对应的标签页。

在输入框中输入网址、标题就可以进行标签页的搜索。搜索结果不仅局限于当前打开的标签页，还包含了近期的历史记录。

2. 书签/历史记录/经常访问标签管理

通过斜杠 + 指令 的方式就能进行模式的切换。目前支持以下三种模式：

  1. 书签/收藏夹管理：输入 /b (bookmark) 此时的列表是收藏夹中的标签。
  2. 历史记录：输入 /h (history) 此时会显示浏览记录，按时间排序。
  3. 经常访问表情：输入 /f (frequent) 此时会显示近期多次打开的页面。

无论哪种模式，输入框都支持搜索。

3. 标签页去重

有时我们会打开多个同样的标签进行对比，那么在关闭时可以使用这个功能进行一键去重。

通过 /dup (duplicate) 展示所有重复的标签页。

4. 搜索/访问功能

搜索框除了支持标签页的检索，也支持 URL 和搜索引擎的调用。

当插件识别到是一个网址时，会自动打开对应的网站；而使用 ctrl + 回车 时，会调用浏览器默认的搜索引擎对内容进行搜索。这样就不要再去地址栏进行操作了。

5. 设置页面

最后插件的设置页面中可以进行语言、颜色、透明度的设置。常用的快捷键也可以在此处查看。

 

一些问题？

1. 这个插件会收费吗？

不会，该插件会采用免费的形式。

2. 怎么确保用户的隐私呢？

不收集任何数据。没有后端，也没有统计埋点。标签页、书签和历史记录都在浏览器本地处理，不会上传。

3. 设置如何同步？

主题、透明度和语言通过 chrome.storage.sync 保存，可以在登录同一账号的 Chrome 设备之间同步。

以上就是这个插件的具体介绍，这是我第一个 Vibe Coding 的小工具。相信仍然有许多改进和优化的空间。
