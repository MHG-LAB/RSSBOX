以实时驱动智能：Apache Doris Summit 2026 盛大落幕，开启 Agentic AI 时代数据新范式

2026 年 10 月 21 日至 22 日，由飞轮科技主办的 Apache Doris Summit 2026 线上技术峰会圆满落下帷幕。本次峰会以 “Powering Real-Time Intelligence for the Agentic Era” 为主题，成功吸引了全球超过 12 万开发者、数据架构师及 AI 技术专家的云端参与，共同见证数据基础设施从“实时分析”迈向“实时智能”的历史性变革。

本届峰会设立了主论坛、实时湖仓论坛以及数据智能论坛三大重磅板块，围绕 AI 多模湖仓、增量计算、Agentic Analytics、可观测性评估与企业级生产落地 等前沿方向，汇聚了来自互联网、金融、国央企、物流、自动驾驶、智能制造等领域的 34 名顶尖专家，为业界呈现了一场贯穿底层引擎创新与上层智能应用的科技盛宴。

升级与蜕变：Apache Doris 5.0 重磅演进

峰会在 Apache Doris PMC Chair 陈明雨题为《从实时分析到实时智能：Apache Doris 5.0 驱动 Agentic AI 时代》的主旨演讲中拉开帷幕。

回顾过去 12 个月，Apache Doris 保持着平均约 3 周迭代一个版本的高频演进节奏，共发布 17 个版本。目前社区累计拥有 760 余位贡献者、109 位 Committer 与 26 位 PMC 成员；GitHub Stars 突破 16,000，主干 PR 超过 4,400 个。开源活动覆盖从国内城市行到新加坡、印度、旧金山、悉尼及欧洲等海外阵地，Apache Doris 开源生态正在全球范围内加速繁荣。

在 AI 时代，数据消费者正从人扩展到 Agent，数据的价值链路也从传统的数据到洞察，演化为数据到上下文再到行动。面对并发量增长 10 到 100 倍且具备强 Ad-hoc 特征的 Agent 查询需求，即将于年底发布的 Apache Doris 5.0 确立了全新的三大演讲主线：

  • 数据层（多模湖仓）：将结构化与非结构化数据纳入统一的分析体系。
  • 计算层（增量计算）：使计算结果随数据变化实现实时更新。
  • 交互层（Agent 式分析）：将 SQL、检索能力与大模型深度结合。

这三个方向的结合，构成了 Apache Doris 5.0 的全新定位：面向 Agent 的数据基础设施，从实时分析走向实时智能。

底层引擎突破与上层 Agentic AI 的深度融合

在 AI Agent 及大模型深度融入业务场景的背景下，数据基础设施面临数据多模态化、计算持续化、交互自然化、链路可观测化以及部署 Serverless 化等关键挑战。在主论坛中，多位技术专家围绕多模湖仓、增量计算以及 Agent 上下文交互三大演进主线，系统展示了 Apache Doris 与 SelectDB 的底层技术架构突破与工程实践。

多模湖仓：存储开放，计算统一

Apache Doris PMC Chair 陈明雨指出，在 AI 时代，多模态数据的统一融合，是 Agent 能够感知真实世界的基石。

在主论坛演讲中，Apache Doris 联合快手、 LanceDB，正式公告了 Apache Doris 5.0 面向 AI 的多模湖仓架构。面对 AI Agent 与大模型应用对数据层提出的“完整、统一、实时”极速上下文需求，Apache Doris 给出 “存储保持开放，查询与执行保持统一” 的全新解法。

换言之，无需将所有数据搬迁至单一存储系统，允许数据保留在各自的开放格式中，而在查询与执行层实现统一。

  • 存储开放，按负载解耦：无需搬迁数据，允许 Iceberg、Paimon、Lance 等开放格式各自承载长期分级、持续更新或多模态数据集；Doris 引擎直接复用湖表原生的向量、全文及标量索引，避免冗余存储与同步开销。
  • 计算统一，单条 SQL 混合检索：打破结构化与非结构化数据壁垒，通过单条 SQL 在同一个执行计划中完成“向量语义召回 + Variant 动态路径过滤 + 跨源多表 Join + 权限过滤”，从根本上解决传统架构“相似但不可用”的痛点。
  • 秒级实时，闭环写回：支持通过 MERGE INTO 等语法将 Agent 产生的标注重构原子写回 Paimon 湖表；借助全新的 Fluss Union Read（流湖一体直读），无缝合成历史快照与秒级实时日志，提供最新的分析上下文。

此外，快手现场分享了基于 Paimon 存储上亿条高维向量并用 Doris 直接检索的生产实践，LanceDB 也展示了多模态 AI 数据集与 Doris 引擎深度集成的最新成果。阿里云产品专家凤豪也分享了 SelectDB 多模湖仓架构在智驾场景的标杆落地，通过对 Paimon 数据湖中 1.28 亿级多模态数据直接检索，实现高达 96% 的向量召回率，性能衰减仅为内表的 1.07 至 1.36 倍。

增量计算：从批量刷新走向持续计算

Apache Doris PMC、飞轮科技存储引擎技术负责人周飞表示，数据越新鲜，Agent 的推理与决策就越贴近真实世界。未来的数据计算不再是定时的批量刷新，而是随着数据流入而发生的持续演进。

为了保证 Agent 在推理过程中获取最新的业务上下文，Apache Doris 5.0 在计算层推出了全新的增量计算架构与异步物化视图行级增量刷新能力（IVM） ，改变了以往依赖定时任务全量或微批刷新的处理逻辑。

底层创新：精准捕获与有状态流控

Doris 5.0 在底层推出了 Row Binlog 与 Table Stream 技术，不仅能精准记录更新前后（Update Before / Update After）的行级数据变更，更实现了有状态的消费位点管理与事务保障。既可通过 Flink Connector 将秒级变更实时推送到外部流计算生态，也可在引擎内部直接驱动计算。

引擎突破：单条 SQL 实现秒级行级刷新

基于 Row Binlog，新一代 IVM（行级增量物化视图） 允许用户通过声明式 SQL 自动维护复杂业务指标。测试显示，在 10 亿级基表数据下，IVM 仅扫描发生变更的数百行数据，在仅消耗传统分区刷新 1/50 资源的前提下，将数据变更至指标查询的 P50 延迟缩短至 0.26 秒，耗时与 CPU 消耗仅为全量刷新的数百分之一。

Apache Doris PMC、飞轮科技查询优化器负责人张文歆补充到，截止目前，IVM 已在电商实时数仓等场景成功落地，实现了发货 GMV 宽表自动拼装与公共维表高效统一加工。此外，Doris 正在将 IVM 与增量计算能力进一步延伸至 Iceberg、Paimon 等开放湖仓格式中，大幅降低数据流水线的维护成本，为企业级 AI Agent 与实时业务决策提供极致新鲜、低成本的数据底座。

Agentic Analytics：Capy Agent 发布，企业级分析新范式

Apache Doris 与 SelectDB 创始人马如悦以“对话你的数据（Talk to Your Data）”为题，正式宣布免费、自托管的 Web 工具 Capy Agent 将于 10 月 31 日发布，并重点阐述了企业级分析 Agent 的技术路线。

  • 专用架构与企业级安全管控：区别于个人及通用 Coding Agent，Capy Agent 采用基于 Web 的私有化部署形态，提供企业级大模型/数据源接入集中管控、精细化权限隔离与全链路安全审计；同时创新性地引入 Markdown as Dashboard 与 Coding MCP，不仅实现了分析结果的动态实时刷盘，更攻克了传统 MCP 协议导致上下文窗口溢出的行业痛点。
  • Markdown 文件系统上下文层：针对大模型数据分析“准确率低”的核心难题，引入了比较前沿的 Markdown 文件系统上下文架构（Context Layer）。通过将数据 Schema、指标语义（Ontology）、业务 SOP 及 Agent 规则统一抽象为结构化的 Markdown 目录树，允许大模型采用原生文件指令进行渐进式读取，将复杂分析任务的准确率从 17% 提升至 86%，并完美支持集成 MetricFlow 等传统语义层。
  • 实时与 Serverless 是 AI 时代的数据底座未来：AI Agent 正在推动分析需求呈现 10 到 100 倍的爆发式增长。面对海量高并发与即时（Ad-hoc）查询，数据底座必须向亚秒级实时查询与 Serverless 极速弹性架构演进。亚秒级是实时分析的底线，而极低的查询延迟与 Serverless 的弹性伸缩，是让高并发、强 Ad-hoc 特征的 Agent 查询真正走向平民化落地的关键所在。

Litefuse：Agent 可观测性与评估平台

Apache Doris Committer、飞轮科技资深开发工程师姜凯强调，在生产环境里面，每天产出几百 TB 规模的 Agent Trace 数据会成为一种常态。而全链路的可追溯与可评估，是建立企业级 AI 信任的唯一解。

针对 Agent 深度参与决策后出现的路径偏离、幻觉及断言正常但业务逻辑错误等难题，姜凯在演讲中展示了基于 Litefuse 和 Apache Doris 打造的 Agent 可观测与评估平台。

  • 可观测侧（Observability） ：基于 OpenTelemetry 与专用 SDK 进行 Trace 采集，支持 100+ AI 生态集成。提供全局调用树展开（耗时、Token、成本逐层下钻）、基于 Session 用户/环境的维度查询，以及线上 Bad Case 一键标注与数据集沉淀。
  • 评估侧（Evaluation） ：结合离线数据集与线上 Trace 回流，支持程序断言与大模型自动评估（涵盖准确率、检索质量与执行轨迹合理性），提供多版本对比实验与基线沉淀。
  • 生态兼容与交付：全面兼容 Claude Code、Cursor、OpenClaw、Pi Agent 等 Agent 框架以及 MiniMax、Kimi、阶跃星辰等模型。提供开源版、企业版（SSO、项目级权限、SCIM 用户生命周期管理）及云托管三种交付形态。

在 1TB 规模 / 6.6 至 7 亿行同源数据基准测试中，Litefuse 展现出领先的优势，导入提升 2.3 倍，总存储节省 35%，高频查询均可亚秒级返回。

千行百业实践：从实时湖仓到 DataAgent 落地

在为期两天的实时湖仓与数据智能论坛中，来自金融、互联网、AI-Native、央国企政府、游戏、交通物流、消费和先进制造等数十个行业的头部企业技术专家，分享了他们如何借助 Apache Doris 或 SelectDB 实现实时多模湖仓、DataAgent 与 AI 应用落地，揭秘海量数据场景下的前沿实践。

在实时湖仓论坛上，来自 Lance、京东零售、华安基金、民泰银行、快手、中通快递、徐工汉云、欣旺达动力、实时未来科技的技术专家，分享了他们如何基于 Apache Doris 或 SelectDB 搭建实时数仓、湖仓一体及加速方案。在数据智能论坛上，来自网易、亚马逊、Datus、土巴兔、哥瑞利、正泰集团、白鲸社区、算秩未来、DataClaw、如祺出行、快猫星云、蓝象智联、NineData、青藤云安全、德灵的技术专家，分享了在 AI Agent 等智能场景下 Apache Doris 或 SelectDB 的落地实践及具体收益。
