分析云202611发版速览：7大硬核功能重磅升级！

本期版本聚焦于增长分析、客户数据平台、智能运营及数据采集能力的持续升级。增长分析进一步丰富多指标可视化、转化对比与行为分析场景，帮助业务人员更高效地发现指标变化与转化问题；客户数据平台增强评分标签能力，为精细化人群运营提供更清晰的价值衡量依据；智能运营持续优化活动编排体验，使触达时机配置更加灵活、精准。同时，数据中心与 SDK 持续扩展无埋点采集和数据治理能力，为全端一致的数据分析提供更稳定的基础支撑。

增长分析

事件分析新增柱线组合图，量率同图提升多指标解读效率

事件分析新增柱线组合图，可在同一图表中同时展示事件触发次数、触发用户数等量级指标，以及人均触发次数、占比变化等趋势或比率指标。适用于需要同步观察“量”与“率”变化的分析场景，帮助业务人员更直观地发现指标关联和异常波动。

漏斗分析支持时间对比，快速定位转化波动环节

漏斗分析支持对比不同时间周期的转化情况，并展示各步骤及整体转化率差异。业务人员可快速定位转化变化发生的环节，为活动复盘、版本效果评估和漏斗优化提供数据依据。

漏斗转化支持最迟发生时间计算，更准确还原转化路径

漏斗分析新增按每个步骤事件最迟发生时间计算转化的口径。在用户多次触发步骤事件时，可更准确地还原转化顺序与各环节耗时，适用于转化周期分析和流失环节诊断。

客户数据平台

评分标签支持加权评分，更准确识别用户综合价值

评分标签支持将用户评分拆分为多个业务维度，并分别配置评分规则与权重，最终汇总生成 0～100 分的综合评分。业务人员可结合实际运营目标，为消费贡献、活跃表现、服务互动等不同维度设定不同的重要程度，避免仅以单一指标判断用户价值。

该能力适用于会员分层、高价值用户识别、潜力客户筛选等场景，帮助运营人员以更贴合业务策略的方式评估用户表现，并据此开展差异化运营和触达。

智能运营

延时触达支持指定时刻发送，更精准匹配运营节奏

智能运营的延时触达除支持延时一段时间外，还可以配置在下一个指定时刻或 N 天后的指定时刻触达。运营人员可根据用户进入策略的具体时间，灵活安排当天、次日或多日后的触达，无需再手工换算等待时长。

例如，用户在晚间进入活动后，可将后续提醒安排在次日上午的指定时间发送；对于需要间隔多日跟进的场景，也可直接配置 N 天后的固定触达时刻。该能力减少了多节点编排与时间计算成本，使触达安排更贴合实际业务节奏。

数据中心

无埋点圈选支持 uni-app 鸿蒙应用，扩展全端采集覆盖

可视化圈选新增支持基于 uni-app 框架开发的鸿蒙（HarmonyOS）应用。业务人员可直接进行页面元素圈选与埋点规则定义，无需单独开发鸿蒙端采集代码。

SDK

曝光时长采集支持全局配置，统一页面数据统计口径

SDK 初始化阶段支持统一配置曝光时长采集规则，无需在各页面分别设置。该能力有助于统一不同页面的采集口径，为页面停留与浏览行为分析提供更可比的数据基础。
