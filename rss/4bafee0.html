如何看待DeepSeek因免费端限额，且无充值入口，被称付费体验直线上升？它们会开放C端个人订阅吗？

赵泠的回答

我认为 DeepSeek 短时间内不会开放 C 端个人订阅。即使算力充足，个人付费订阅依然会带来一系列麻烦：客服、支付与退款[1]、权益体系维护[2]、合规和消费者保护[3]。眼下，想要 C 端个人应用的用户可以去找调用 API 的第三方应用。

这问题展示的截图显然是大语言模型生成的文本，这段文本并没有对网传的“付费体验直线上升”进行直接解释。新闻事实是，“DeepSeek 的免费 C 端被限额后，资源向付费的 B 端 API 倾斜，一些开发者调用 API 的体验变好”。一般认为这反映 DeepSeek 的算力紧张。DeepSeek 的 C 端免费版与 B 端 API 使用彼此隔离的资源池，限制 C 端后回收的算力被用来保障付费 API 的稳定性。

这问题展示的截图里“V4.1 Flash 单周 Token 调用量居全球首位”的说法来自某些拿 OpenRouter 的数据做夸大宣传的媒体和“自媒体”，这跟 DeepSeek 限制免费用户的做法摆在一起，产生了强烈的讽刺效果。

  • DeepSeek V4.1-Flash-1017 物美价廉，在 OpenRouter 吸引了大量用户，尤其是从更早版本的 DeepSeek 迁移过来的用户。不过，OpenRouter 的统计数据只能代表他们自己。“单周调用量达到 33.6 万亿 Token”就能拿下第一，这体现了 OpenRouter 的规模之小。
  • 2026 年 10 月 19 日至 25 日，OpenRouter 一周的 Token 调用量约 188 万亿。作为对比，中国信通院的数据显示，2026 年 6 月，我国每天的 token 消费量就达到了约 500 万亿，你可以想象一下 2026 年 10 月同期我国每天的 token 消费量。

当然，我们的媒体不是头一次拿OpenRouter 的统计数据胡说八道。可以回顾：中国AI调用量首超美国，国产算力电力大涨，英伟达市值一夜蒸发 2600 亿美元，如何解读背后市场信号？

中国某些人工智能厂商在 OpenRouter 的 API 调用量（以 token 计）涉及免费提供或低价提供的大把 tokens. 一些“智能体”工具，例如 OpenClaw，会剧烈消耗 token. 近来，一些美国人工智能厂商禁止用户以优惠价格拿他们的产品驱动这类工具，一些欧美用户报告他们改用了中国产品。
缺失定语的“中国AI调用量首超美国”与“英伟达股价暂时下跌”这两个现象在时间上先后发生，并不代表前者是后者的原因。现实中，市场比这种简单的二元叙事要复杂得多。类似地，全球海盗活动减少并不是全球近地表平均气温上升的原因。
