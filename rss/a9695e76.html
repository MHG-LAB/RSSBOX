受够了托盘常驻五六个工具：开源一个轻量原生 Windows 工具箱 Tools3000（文件/全文秒搜、截图贴图、离线 OCR、鼠标手势、自动运镜录屏）

yuan278501381:

我是 Everything 十多年的老用户；截图软件最早用 QQ、微信截图，后来换到标注方便的 FastStone Capture，再之后换到可以贴图的 Snipaste，后来因为需要滚动长截图、截图放大镜和文字识别，又换到了 PixPin；鼠标手势从 WGestures 用到支持脚本的 WGestures 2；录屏软件也换过一圈，中间也试过微软 PowerToys，但总差那么几块核心拼图，最后系统托盘里还是常驻着五六个图标。

再加上日常使用一直被几个小痛点膈应：

  • Everything 日常默认只按文件名搜，忘掉文件名想直接搜 Word / PDF / Excel / 代码里的正文内容很不顺手；
  • PixPin 的 OCR 在代码和复杂排版上的识别率与速度，用起来始终差口气；
  • WGestures 2 莫名会在屏幕上残留一个很小的文本框挡视线，只能重启解决。

现在有 AI，我干脆自己动手用 C++20 + Rust + Direct2D 撸了一个原生 Windows 多合一效率工具 Tools3000，GPL3.0 开源。

发出来之前，我自己重度当主力用了 4 个月——最开始老软件全开着兜底，哪里不顺手切回去，修完再切回来。到现在，我的系统托盘终于只剩 Tools3000 这一个图标。

核心功能一览（100% 本地离线、无账号、无广告）

  1. 文件与文档正文秒搜 + 空格预览

    • Alt + Space 呼出，NTFS MFT + USN Journal 毫秒搜文件名，支持全拼和首字母（比如 wx）；
    • 输入 content: 用 Rust SIMD 内核穿透搜索 Word / Excel / PDF / PPT / CAD / 源代码正文，高亮上下文、点行号一键复制；
    • 选中结果按 Space 免打开快速预览（图片、Office、PDF、代码、CAD、PSD、3D 模型）。
    • 搜索服务严格 DEMAND_START 按需启动，绝不拖慢开机。

  2. 智能截图、长截图、贴图分组与高精度离线 OCR

    • F1 截图标注，自动穿透吸附现代应用界面控件（浏览器、VS Code、Electron、WinUI3、资源管理器），滚轮 / Tab 多级切换，纯图/远控盲区也能视觉补全闭合卡片；
    • 默认虚线光学放大镜、自愈步骤序号、马赛克、滚动长截图（支持首尾无损裁切）；
    • F3 置顶贴图与多贴图彩色分组管理（按组显隐、一键磁吸平铺）；
    • 纯离线 OCR，识别准确率优于微信截图，贴图后可以直接划选复制文本（也支持画波浪线和原位改字）。

  3. 录屏与自动运镜演播室

    • 录屏联动键鼠回显，停止直接进入演播室，支持声波剪辑与鼠标运镜自动聚焦，一键导出 MP4、微信直发 GIF（自动分档防超限）和动态 WebP。

  4. 全局鼠标手势、触发角与桌面小增强

    • 按住右键一划切标签/后退/关窗、不松键瞬发、屏幕边缘滚轮调音量、全屏游戏自动避让、内置 Lua 扩展；
    • 附带系统「打开/另存为」弹窗路径快捷跳转条，还能解决用 mstsc / RustDesk / ToDesk / 向日葵远程桌面时，有些组合键按不动或修饰键卡住的问题。

工程细节（拒绝 Electron 吃内存）

  • 轻量待机：非 Electron，原生 Win32 + Direct2D 渲染浮层，设置页 WebView2 关窗可自动释放，主程序日常待机约十余 MB；
  • 文件索引服务实测内存（按需启动）：搜索索引服务严格 DEMAND_START，只在首次呼出搜索时启动，内存占用取决于本机磁盘文件量——我自己文件较多的常用主力机实测约 300 MB，干净虚拟机测试约 100 MB；如果不呼出搜索，这项占用为 0 MB；
  • 短命子进程隔离：离线 AI OCR（DirectML）和视频硬件编码（FFmpeg/QSV/NVENC）均放在独立短命子进程里跑，闲置或导出完立即退出，由操作系统 100% 回收物理与虚拟私有内存，避免驱动长驻吃掉几百 MB；
  • 架构与系统支持：原生支持 Windows 10 / 11 / Server 2019–2025（含 Server 多用户并发办公），源码支持 x64 与 ARM64，内建 8 种界面语言。

客观对比：它不能完全替代什么？

无意否定任何老牌专精软件，Tools3000 覆盖的是日常 90%+ 的组合高频场景。如果你重度依赖以下专精能力，依然建议保留原工具：

  • Everything 的 HTTP/ETP 局域网搜索、EXIF 属性列索引或 es.exe CLI 生态；
  • ShareX 的 80+ 图床/S3/Webhook 自动上传流水线；
  • StrokesPlus 极其复杂的组合键与窗体区域宏脚本。

安装与安全验证

  • GitHub 仓库：https://github.com/yuan278501381/Tools3000
  • 最新版本下载（含安装包与绿色便携版）：https://github.com/yuan278501381/Tools3000/releases/latest
  • 包管理器一键安装：
    • Winget：winget install Yy1.Tools3000
    • Scoop：scoop bucket add tools3000 https://github.com/yuan278501381/Tools3000 && scoop install tools3000/tools3000

每个 Release 均附带 SHA256SUMS.txt、VirusTotal 哈希直链及 SBOM.spdx.json 软件物料清单。因为个人开源项目尚未购买商业 EV 签名证书，首次运行安装包若遇 SmartScreen「未知发布者」提示，核对哈希和 VirusTotal 后点「更多信息 -> 仍要运行」即可，也完全欢迎直接看源码从零编译。

桌面环境千差万别，欢迎各位 V 友拍砖、提 Issue 或直接提 PR 一起打磨。
