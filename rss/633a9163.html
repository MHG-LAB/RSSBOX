招 1 名全栈工程师（AI 伴侣方向）

yjpeminem0604: 已在 V2 上有多名小伙伴稳定在职，现在新出来一个全栈岗位空缺

项目稳定，长期，纯远程团队，项目看板+日报+agent 的内部管理形态，配合透明友好

如果简历合适，我们有测试题目的环节

薪资标准：18-30K ，每月 5 号发薪，有季度奖金

岗位职责

平台全栈开发：负责用户系统、角色管理、聊天交互、内容社区、订阅支付及运营后台等功能的设计、开发与迭代。
AI 应用与 Agent 开发：负责大模型接入、提示词管理、上下文与长期记忆、知识检索、工具调用及任务编排，提升角色一致性和互动体验。
ComfyUI 与多模态接入：负责 ComfyUI 工作流的调试、API 封装与平台集成，接入图片、语音、视频等模型服务，打通生成、存储、展示的完整流程。
工程质量与性能优化：完善异步任务、队列调度、流式响应、失败重试及监控机制，优化响应速度、服务稳定性和生成成本。
跨团队协作：与产品、内容及运营团队共同设计功能，将角色设定、内容素材和互动规则转化为可上线、可配置、可持续迭代的产品能力。

岗位要求

具备独立交付 Web 产品的能力，熟悉 TypeScript 及 React/Vue 等前端技术，掌握 JAVA 、Python 或 Node.js 等后端技术，具备数据库、缓存、接口设计及部署经验。
有实际上线的 LLM 应用或 Agent 项目经验，理解提示词、上下文管理、RAG 、工具调用等机制，能够定位和改善 AI 输出质量问题。
熟悉 ComfyUI 工作流及 API 调用，具备 Python 开发能力，能够将工作流接入业务系统，处理生成任务状态、异常及结果回传。
有良好的产品意识，重视聊天、多媒体展示及移动端交互体验，能够兼顾开发效率、系统可维护性和使用成本。
具备主动推进和跨团队沟通能力，对 AI 伴侣及角色互动产品有兴趣，能够接受成人向产品业务场景。

加分项

有 AI 伴侣、角色扮演、互动娱乐或创作者平台开发经验。
有 ComfyUI 自定义节点、多模态模型部署、GPU 任务调度或推理优化经验。
有实时语音、视频互动、海外订阅支付或 UGC 社区开发经验。
