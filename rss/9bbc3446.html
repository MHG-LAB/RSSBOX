LinkTap - 点击复制链接地址｜Chrome 扩展

最近因为要保存一些页面，所以需要批量复制一些网页链接，但完全写个纯自动化的应用又有点大动干戈，于是就做了一个按住键盘修饰键，点击直接复制链接地址的 Chrome 浏览器扩展。使用 Codex 开发。分享给有同样需求的朋友。

Chrome 小工具 - LinkTap

功能介绍

按住自定义修饰键，再点击网页链接，就能直接复制 URL，不会打开新页面。

如果你想批量复制一个网页上的很多链接，可以结合剪贴板历史管理应用使用。（如 Pastebot / Paste / PasteNow 等，Alfred / Keyboard Maestro 等应用也带有剪贴板管理功能。）

  • 自定义 Ctrl / Control、Alt / Option、Shift、Command 组合
  • 支持单键、双键、三键及四键组合
  • macOS Control + 点击兼容
  • 支持简体中文、繁体中文、英语、日语和韩语
  • 完全本地运行，无广告、无统计，不上传浏览记录

权限说明：为了在任意网页识别被点击的链接，插件需要在网页上运行。当前版本只在触发快捷键时读取被点击链接的 URL，并将其写入剪贴板。
