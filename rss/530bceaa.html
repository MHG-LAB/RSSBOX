一份用"工程师思维"写的人生指南：472 条建议，每条都标了证据等级

你有没有想过，把"怎么活得好"也写成一份带证据等级、能按条件筛选的需求文档？

还真有人做了。而且是个程序员。

它是什么

高性价比人生指南（HowToLiveBetter），一个完全开源的人生建议库。目前 472 条，每条只回答两个问题：

花掉什么？ （钱 / 时间 / 精力 / 毅力） 换回什么？ （寿命 / 钱 / 时间 / 人身自由）

每条还标了证据等级：A 是荟萃分析、大型队列或 RCT 给的具体数字；B 是有研究但难量化；C 是经验和共识。有争议的条目会同时把反方证据列上，不藏着掖着。

最妙的是它能筛选：选「不花钱」+「不用毅力」，立刻过滤出一堆"顺手就能做、几乎零成本"的改变。作者明说：这不是任务清单，挑走一两条就算数。

为什么程序员会喜欢

因为它不是鸡汤，是 spec。

  • 量化：系安全带——0 元，每次上车 2 秒，车祸死亡或重伤概率大约降一半。
  • 可溯源：来源只引原始文献（附 DOI）和官方文件（gov.cn、最高法、最高检），知乎、公众号、搜狐这类二手转述一条不引。每个数字都能在原文里找到，找不到就标 TODO。
  • 口径隔离：寿命年数和省下的钱不在一把尺子上硬折算，不假装能算出一个总分。
  • 机器可校验：仓库里有 linter 和 CI，引用漂了就像编译器报类型错——你信不信它，不靠信作者，靠它能追溯。

把"怎么活"做成"内容即构建流水线"，这本身就很工程师。

几个让我记下的条目

  • 把食盐换成低钠盐（钾盐） ：每袋贵几元，脑卒中降 14%、心血管事件降 13%、总死亡率降 12%，证据 A。备注也写了禁忌（肾功能不全、吃保钾利尿剂的人别用）。
  • 系安全带，前后排都系：证据 A，成本就是上车 2 秒。
  • 程序员和技术人容易踩的红线、普通人法律红线：这两章对我们这种人尤其实用。
  • 紧急情况先做什么、结婚划不划算（长文）：都是人在慌乱时最难冷静想清的事，它提前写好了。

为什么我愿意推荐

满屏都在拿"AI / 认知差"卖课，这人反手把 472 条带证据的人生建议全开源免费发，连能装进 Claude Code / Codex 的 AI 问答技能都免费给。协议是 CC BY / Unlicense，随便用。

这种"把好东西摊开、不收费、还给你核查工具"的做法，在现在的环境下反而稀罕。

怎么用

  • 直接开在线检索页，按需筛。
  • 想离线或自己改，GitHub 自行 clone：github.com/eternity471…
  • 想随时问，把它的 skill 装进 Claude Code / Codex，当私人顾问。

别想着全做。作者自己都说没做到大部分。挑一两条，今天就改，够了。
