Dashboard：把 iPad 变成HomeKit 控制屏

  • 平台：iOS、iPadOS
  • 关键词：HomeKit、智能家居

@waychane：Dashboard 是专为 iPad 设计打造的 Apple Home 控制屏，它同时也能在 iPhone 上使用。Dashboard 会把你的家庭设备、摄像头、天气、日历等信息，集中到一个可自由排列的 iPad 仪表盘当中，非常适合放在玄关、客厅或卧室作为家里的固定控制中心。

Dashboard 没有照搬 Apple「家庭」的界面，它把每一个设备都变成了可以自由调整的磁贴。你可以长按磁贴，将它拖到面板上的任意位置，并通过右下角手柄调整大小；不同设备可以拥有完全不同的尺寸。iPad 客户端支持分页，iPhone 则采用单页滚动布局，设备磁贴可以直接隐藏，因此你完全可以按照自己的家庭环境设计一套专属的操作面板：将客厅摄像头做成最大的磁贴，下面再安排天气、日历和时钟；右侧摆放灯光、空调和窗帘等。对于那种将 iPad 固定在墙上的用法，这种布局比打开「家庭」App 后逐层找设备更加直观。

Dashboard 可以读取 Apple Home 中的各种设备，包括灯光和开关、温控器、温度传感器、百叶窗和卷帘窗帘、门锁、各种环境传感器等。其中灯光可以直接调整亮度，支持灯光颜色和色温；窗帘和百叶窗也可以精确到 1% 调节。

Dashboard 的另一个核心功能是 RTSP 摄像头支持。家里的摄像头即使没有接入 HomeKit，只要能够提供 RTSP 视频流，也可以直接加入 Dashboard。应用支持 H.264 和最新加入的 H.265 RTSP 视频流，并兼容海康威视、大华、Reolink、Axis 等设备。更方便的是应用内提供了局域网摄像头搜索，对于支持 ONVIF 的摄像头，它可以自动寻找视频流地址；其他设备也会尝试常见的 RTSP 路径，减少手动填写地址的麻烦。

如果你愿意进一步折腾，Dashboard 还提供了 3D 平面图功能。你可以导入房屋平面图，然后把 HomeKit 设备放置到对应的位置，最终得到一张可以直接操作的家庭 3D 平面图，点击平面图上的设备即可进行控制。另外 Dashboard 支持多楼层且每一层都可以独立设置。

Dashboard 可以在 App Store 免费下载使用，免费版有可添加设备数量限制，在 2～4 个左右，Premium 版本在解除这些数量限制的基础上，提供 3D 户型图、灯光高级控制、配置备份等高级功能，费用是 9.99 美元 / 年，支持 7 天免费试用。

Adaptive Theme：更聪明的自动深浅色模式切换

  • 平台：Android
  • 关键词：深色模式、自动、自动化

@克莱德：乘车经过隧道时被明亮的手机照亮脸庞，或者烈日当空的时候从漆黑的背景里找文字——两种类似的场景你或许都经历过。所以环境暗时自动切换深色模式、环境亮时自动切换浅色模式，绝对是个长期被忽略、却一直没被满足的小众需求。

Adaptive Theme 这款小工具瞄准了这个痛点，它的的工作原理很简单：每次亮屏时读取一次当前的环境亮度，然后基于亮度调整设备的深色或浅色模式。你可能会说整个思路在动手能力强的朋友手里用 Tasker 两分钟就能搓出来，但 Adaptive Theme 显然比 Tasker 好看。并且因为借用了 WRITE_SECURE_SETTINGS 这个权限，Adaptive Theme 的配置过程也多种多样：root、Shizuku、网络 ADB 调试或者开发者自建的网络授权工具，选择你顺手的即可。

授权后我们就可以开始自定义设置了。应用在这里提供了六个常用的默认亮度阈值，手机振动马达不错的机型在滑动调节时能感受到细腻的振动反馈，为了方便你判断那个阈值合适，滑块下方还有当前使用环境所对应的实际亮度数值。自定义阈值功能则藏在右上角的三点菜单当中。

从上往下，夜间模式考虑的可能是「晚上上厕所开个灯但不想手机为此切换到浅色模式亮瞎眼」的场景，可以让手机在设定时段内保持的深色模式；壁纸和模糊锁屏则算是一点加分项，你可以为深色模式和浅色模式分别设置不同的壁纸，并且在锁屏为这些壁纸应用一个模糊滤镜。

配置好之后的实际运行机制也值得一提：Adaptive Theme 不会在你使用过程中实时切换浅色和深色模式，它采用了类似 Android 系统级深色和浅色模式切换的方案，仅在你点亮屏幕的瞬间完成模式切换的决策，保证每次点亮屏幕后，系统的主题模式都是符合当下光线环境的。另外实测自动换壁纸功能的确如应用界面的介绍所说，亮屏时会有一两秒左右的延迟才会切换完成。

总体而言 Adaptive Theme 算是为 Android 系统自带的浅色和深色模式切换提供了应有的补充，并且配置门槛不算高，在厂商引入类似的机制前不妨常备在手机里。你可以在 Play 商店免费下载 Adaptive Theme，应用免费开源，GitHub 项目主页还有其他下载渠道。

Voxt：基于 AI 的语音输入和翻译工具

  • 平台：macOS
  • 关键词：语音、输入法、AI

@化学心情下2：今年很多基于 AI 的语音输入应用大量涌现，相信不少朋友也都尝试了包括豆包输入法在内的工具，虽然这些工具能在一定程度上解放双手，但依赖远程大模型来实现转录动作的方案，在无法访问网络的环境下显然也会碰壁。

而使用本地大模型来实现语音输入和撰写的工具就可靠一点，今天介绍的 Voxt 正是其中之一。

Voxt 已包含多种语音和文本转换工具，相比其他市面上提供的完整产品或解决方案，Voxt 提供了相对开放的方案：你可以接入远程大模型，填入 Token 来实现转录、翻译、撰写等操作，也可以充分利用 macOS 的本地模型能力，通过本地的大模型来实现上述功能。

以我个人常用的转录、翻译和改写场景为例（当然 Voxt 还有笔记、会议等功能，我因为遇到的场景不多这么不专门描述）：先说转录，在需要插入文本的地方按下 Fn 快捷键，然后就能在屏幕中下方看到一个语音录入图标，直接开口说话，Voxt 会在图标下方显示转录的文本内容预览，再按下 Fn 就会把转录的文字插入进来。

翻译功能与之类似，选中一段文本，按下快捷键 fn+Shift 就能在屏幕图标下方看到翻译后的文本预览，阅读一些本地文档时可以快速翻译文本，了解具体内容。

我个人使用的比较频繁功能则是改写。选中一段文本后，按下 fn+control 即可通过语音发送改写指令，比如「将文本改成更正式的语气」或者是「帮我精简下」，稍等片刻即可看到改写的结果预览（取决于模型能力）。

总的来说，Voxt 在一定程度上确实实现了本地高性能转录、翻译等能力，加上针对 Apple Silicon 的专项优化，以往必须联网才能实现的部分语音输入功能，现在也可以在本地试试了。如果你有类似的需求不妨试试 Voxt，你可以在其 GitHub 主页中下载以及了解具体的用法。

MicYou：把手机变成电脑的高清外接麦克风

  • 平台：Android、Windows、macOS、Linux
  • 关键词：麦克风、手机、跨设备

@大大大K：前几天临时要录一段口播，家里电脑却是老式的耳机麦克接口。翻箱倒柜找不到能用的麦克风，手头唯一能收音的设备只有手机。那能不能把手机变成电脑上能用的麦克风设备呢？

我找到了这款体验相当不错的开源工具 MicYou。

MicYou 分为手机端和电脑端，电脑端相当于一个虚拟的麦克风设备，接收手机端收音后的推流。两端支持 Wi-Fi 局域网连接或者 USB 有线连接，前者使用更加灵活方便，只要手机和电脑处于同一局域网环境，打开客户端后就能快速完成配对；后者的实时性更好，也不会受限于复杂的网络环境。另外 MicYou 还提供了一个「Web 模式」，电脑端开启后只需用手机浏览器扫描屏幕上的二维码，就能直接借助 Web API 收音并推流给电脑，手机端甚至连客户端都无需安装。

电脑端启动后，系统里会出现一个新的麦克风设备，此时我们可以直接在系统里更改默认麦克风，或者去第三方应用里（比如在线会议、OBS 应用等）手动选择该麦克风，就能直接收录手机端的音频流了。

MicYou 内置了一系列高阶的音频流处理算法，包括 AI 降噪、混响、回声抑制、自动增益控制甚至是均衡器的调节；在收音过程中我们也能实时看到电平高低、延迟和丢包数据，并支持开启耳返监听模式。实际使用时这些处理功能效果还是很不错的，比如我录制口播时因为靠近电脑机箱的风扇开启了 AI 降噪，风扇风噪杂音明显减弱了许多，最终的声音效果也比较干净。

当然，受限于手机本身的硬件素质，最终的收音效果自然比不上专业麦克风，平时偶尔用一下、临时拿来应急还是可以的，至少能保证手头时有一个可用的收音方式。MicYou 手机端仅支持 Android 设备，桌面端支持 Windows、macOS 和 Linux，你可以在 GitHub 免费下载 MicYou。

Moment Pro Camera II：慢快门、拍摄辅助与更自由的相机界面

  • 平台：iOS
  • 关键词：相机、第三方、手动控制

@Vanilla：Moment Pro Camera II 是 iOS 平台上的一款第三方摄影应用，主打各类进阶摄影功能，可以为 iPhone 摄影爱好者提供更多接近专业相机的拍摄体验。

近期 Moment Pro Camera II 迎来了多次更新，从 1.3 到 1.3.4 的诸个版本更新内容中，包括了慢快门、拍摄辅助和定制化相机界面等更新。我们一起来看看吧。

在 1.3 版本中，Moment Pro Camera II 添加了一种全新的拍摄模式——慢快门，它可以让我们设置一段持续时间，并将该时长内拍摄的帧融合成一张照片。目前 Moment Pro Camera II 的慢快门提供了光轨和动态模糊两种模式，可以通过点击拍摄界面顶部中央的区域进行设置。在这个设置界面中我们可以预先调整持续时间，也可以切换到 Bulb 模式，并在准备好时手动结束曝光。

光轨对应的是车灯、摩天轮、烟花棒等拍摄对象，这些移动光源会在画面中拖出轨迹，而它们背后的场景保持不动；动态模糊则对应了水流、云朵、人群等拍摄对象，这些持续运动的事物会变得模糊，同时静止的物体则保持清晰。

在近期更新的多版本中，Moment Pro Camera II 持续优化了视频和拍照的辅助功能。在 1.3.1 版本中，开发者加入了更高等级的防抖功能、全新的假色选项和对焦放大镜；在 1.3.4 版本中，开发者又进一步改善了 Moment Pro Camera II 在高防抖等级下的录像启动体验。同时，Moment Pro Camera II 中的 Natural 模式支持了变焦和焦距支持，同时在兼容的设备上添加了 24MP 镜头的拍摄。

最后，Moment Pro Camera II 继续为拍摄界面的定制化提供了更多的选项。在 Action Plates 中，开发者为 Techno 和 Swatch 模板加入了自适应控件，并为 MPC-II 和 Techno 模板新增了颜色定制功能。另外，曝光滑块部分也提供了布局设置选项。

可以说，Moment Pro Camera II 朝着越来越专业的相机体验在一直努力。如果你是一名 iPhone 摄影爱好者，希望通过 iPhone 来创作更多严肃的作品，那么 Moment Pro Camera II 会是一个非常不错的选择。Moment Pro Camera II 可以在 App Store 下载，售价是 9.9 美元，没有内购订阅选项。

X Progress 7.0：更「自由」的时间事项管理

  • 平台：iOS
  • 关键词：倒数日、纪念日、提醒

@Snow：选择使用 X Progress 记录倒数日或纪念日，有趣且丰富的卡片主题风格绝对是重要驱动力之一。前两周更新的 7.0 版，X Progress 带来了更自由的发挥空间——让你自己动手创作全新的、属于自己的主题。

点击打开底部液态玻璃抽屉中的「发现」一栏，就可以看到全新的「照片主题工作室」，借助这一功能，你可以将自己的照片素材创作成随时可用的 X Progress 卡片主题。应用支持自定义卡片背景、文字显示和进度指示器，添加背景素材时 X Progress 还支持实况照片，以其作为背景的主题在进入卡片时自动播放实况，实况够有趣，不用任何额外修饰就会是一款非常生动的主题。

只有静态素材也不用担心，借助自定义指示器和动画也可以将主题设计得非常有趣。添加指示器时，X Progress 会自动识别图片中的主体元素并把它们「抠」出来备用，这两天刚预约到浙博《韩熙载夜宴图》的展览，我正好向顾闳中取个材，将韩熙载和它的宾客们抠出来，放到素净的绢本素材上，再分别配置摆动和弹跳的动画效果，韩熙载哪天摇摇晃晃摇到了他的宾客身边，就是我去一睹宋摹本真容的时候了。

除自定义主题外，7.0 版的「自由」还体现在进度显示上。以前我们习惯于追踪倒数事项「还剩多少天」，但新版并不局限于「天」这个计数单位，也并不一定将结束日期敲定为事项节点。你可以选择「天数」或「百分比」来呈现进度，并按自己的需求调整「计数方向」，可以按指向结束的「剩余」标记，也可以按从开始计数的「已过」统计。打开卡片详情，底部还会延伸出一根支持自由拖动时间线，滑动时间标尺可以直观地预览当前事件在不同时间点的状态，在管理项目周期这类有明确起止时间的事件时，会比盯着一个倒数天数更加有效。

此外，7.0 版的开始或结束时间设置也从「日期」细化到了「分钟」，事件提醒进而也变得更加灵活，支持设置多次提醒和重复提醒，并且最小提醒间隔也压缩到以小时为单位。

在 5.x 版中，X Progress 增加了禅模式的「同播共享」，可以邀请你的伙伴们同步专注。新版中共享能力再度提升，你可以邀请朋友或家人直接查看或编辑某个事件，所有修改都会通过 iCloud 同步，参与者可以在共享动态看到谁修改了什么。在处理一些多人参与的项目时时间节点实时同步，这一更新会非常实用。

X Progress 7.0 还增加了对 Apple 智能的支持，在启用 Apple 智能的设备上，你只需说一句话，或提供一张照片，应用就可以创建相应事项。只是不知这项更新中国大陆的用户还需要等待多久才可以真正用上。

X Progress 包含一个内购项，你可以按 1.99 元/月 或 19.9 元/年 订阅，也可以一次性支付 148 元买断。付费后将解锁自定义事件上限（免费用户仅可创建 5 条自定义事件）和全部设计师主题，并支持在 iPad、Mac 和 Apple Watch 上使用。月度、年度订阅分别提供了 3 天和 7 天的免费试用，你可以在试用全功能后再行决定是否付费。

你可以在 App Store 上免费下载 X Progress。
