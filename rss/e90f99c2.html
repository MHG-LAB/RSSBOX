从 Windows 换到 Mac 三个月，我真香了

我用了快十年的 Windows，从 Win7 到 Win11，中间换过四五台笔记本，从来没想过有一天会用 Mac。总觉得 Mac 是设计师和果粉的玩具，写代码还是得 Windows。

直到三个月前，公司给配了台 MacBook Pro 14 寸，M5 芯片，32G 内存。一开始我是抗拒的——键位不习惯、软件不会装、窗口管理别扭，各种不适应。但用了三个月下来，我只能说：真香。

今天就来聊聊，一个十年 Windows 老用户换到 Mac 的真实体验，哪些地方让我抓狂，哪些地方让我回不去了。

刚换过去的崩溃瞬间

快捷键全乱了，手指在打架

刚拿到 Mac 的第一周，我的手指是混乱的。

  • 想复制，按了 Ctrl + C，没反应。哦对，Mac 是 Cmd + C。
  • 想切换窗口，按了 Alt + Tab，跳出来的不是窗口切换器。哦对，Mac 是 Cmd + Tab。
  • 想关闭窗口，点了左上角的 ×，结果只是关了窗口，程序还在后台跑。
  • 想最大化窗口，点了左上角的绿点，结果进入了全屏模式，不是最大化。

这种肌肉记忆的冲突，真的让人抓狂。有好几次我气得想把电脑砸了，觉得"这什么反人类设计"。

大概过了两周，手指才慢慢适应过来。现在让我回去用 Windows，反而觉得 Ctrl 键太远了不好按。

安装软件：拖进去就完了？

Windows 装软件是"下一步、下一步、完成"的无脑流程，虽然会偷偷装全家桶，但至少简单。

Mac 装软件一开始让我懵了——下载下来是个 .dmg 文件，打开之后是个窗口，里面有个应用图标，还有个 Applications 文件夹的快捷方式。然后呢？要干嘛？

后来才知道，把应用图标拖到 Applications 文件夹里，就装好了。就这么简单？对，就这么简单。

但这个"拖"的动作，对 Windows 用户来说太反直觉了。我第一次装软件的时候，双击了应用图标，结果程序直接在 dmg 镜像里跑起来了，关了之后就找不到了，还以为装失败了。

习惯之后觉得真香——没有注册表、没有系统目录污染、卸载直接把应用拖到废纸篓就行，干净利落。

窗口管理：这也叫窗口管理？

Windows 的窗口管理是真的好用——拖拽到屏幕边缘自动分屏，Win + 方向键 控制窗口位置，任务栏一目了然。

Mac 的窗口管理，一开始让我觉得"这也能用？"

  • 没有窗口吸附，拖到边缘不会自动分屏。
  • 没有最大化按钮，绿点是全屏。
  • 最小化之后窗口缩到 Dock 里，想找回来还得点 Dock。
  • 同一个程序开多个窗口，切换起来很麻烦。

我当时的第一反应是：就这？ 后来装了个叫 Rectangle 的免费软件，才把窗口分屏找回来。再加上 Mac 自带的三指上滑看所有窗口，体验才勉强追上 Windows。

但说实话，纯原生的窗口管理，Mac 确实不如 Windows 好用。

用了之后真香的地方

触控板：我再也不想用鼠标了

这一条我必须放在第一个说，因为它对我的改变最大。

之前用 Windows，我是离不开鼠标的人——触控板？那玩意能用？直到我用了 Mac 的触控板。

Force Touch 压感：拖动文件的时候，划到位置稍重按一下就放下了，手指不用离开触控板。这个细节看起来小，但用惯了之后，用 Windows 的触控板总觉得"差点意思"。

各种手势：三指上滑看所有窗口，四指捏合回桌面，三指左右滑切换桌面，双指轻点右键。这些手势一开始觉得花里胡哨，用熟了之后，效率比鼠标还高。

现在我用 Mac，基本不接鼠标。出差的时候少带一个鼠标，包里轻了不少。

续航：一整天不插电的安全感

我之前用的 Windows 笔记本，续航大概 4-5 小时，出门必带充电器，到处找插座。

换了 Mac 之后，续航给我的冲击是最大的——

  • 写代码、开 Docker、跑本地服务，撑 6-8 小时没问题。
  • 轻度办公，一整天不插电。
  • 出差坐高铁，从北京到上海，电脑不用充电。

这种"不插电也能用一天"的安全感，是 Windows 给不了的。现在我出差，充电器都懒得带。

无风扇：真的安静

M 系列芯片的 Mac，大部分时候风扇是不转的——完全静音。

我之前用 Windows，一开 IDE 风扇就开始转，编译代码的时候更是吵得像吹风机。换了 Mac 之后，写代码、跑测试、开十几个标签页，风扇基本不转，安静得我有时候怀疑电脑是不是死机了。

对于喜欢安静环境的人来说，这一点真的很重要。

屏幕和音响：硬件确实顶

Mac 的屏幕，我只能说——用了就回不去。

  • 色准很准，修图、设计不用怕偏色。
  • 亮度很高，在太阳底下也能看清。
  • 细腻度够高，看文字、看代码很舒服。

音响也是，Mac 的扬声器在笔记本里属于第一梯队。看电影、听音乐，比同价位的 Windows 笔记本好太多。

生态联动：手机电脑无缝衔接

我之前用的是安卓手机，换了 Mac 之后顺手换了 iPhone，然后我才明白什么叫"生态"。

  • 手机复制的内容，电脑直接粘贴。
  • 手机来电话，电脑直接接。
  • AirDrop 传文件，秒传，不用插线不用登录。
  • 手机拍的照片，电脑相册里自动出现。
  • 通用剪贴板、接力、随航，这些功能用了就回不去。

Windows + 安卓也有类似的功能（比如"你的手机"应用），但体验和苹果的原生联动比，差了不止一个档次。

系统稳定：不折腾也是一种幸福

用 Windows 的时候，我经常干这些事：

  • 装杀毒软件，定期扫描。
  • 清理注册表，优化系统。
  • 卸载流氓软件，查弹窗是哪来的。
  • 系统更新后出问题，回滚版本。

用了 Mac 之后，这些事基本都不用干了——

  • 没有病毒（至少普通用户遇不到）。
  • 没有弹窗广告。
  • 没有流氓软件捆绑安装。
  • 系统更新基本不会出问题。
  • 用了三个月，一次蓝屏都没有。

不折腾，也是一种幸福。

Mac 让我不舒服的地方

接口太少了

Mac 的接口少，这是真的烦。

  • 我的 MacBook Pro 14 寸，有三个雷电接口和一个耳机孔。
  • 一个雷电要充电，剩下两个要连显示器、U盘、鼠标。
  • 想同时插多个设备？必须接扩展坞。

扩展坞这东西，便宜的不稳定，贵的又沉又占地方。每次带电脑出门，包里除了电脑还要塞个扩展坞，烦。

游戏基本不能玩

Mac 能玩游戏吗？能。但体验和 Windows 比，就是荒漠和绿洲的区别。

  • Steam 上大部分游戏没有 Mac 版本。
  • 即使有，性能也通常比 Windows 差。
  • 新游戏基本不会优先适配 Mac。

我之前用 Mac 的时候，想玩个游戏只能装双系统或者用云游戏，体验非常割裂。

不能升级硬件

Mac 的内存、存储、电池，基本都是焊死在主板上的，买的时候选多少就是多少，后期不能升级。

  • 32G 内存用了两年不够了，只能换电脑。
  • 512G 存储满了，不能加硬盘。
  • 电池老化了，换电池的钱够买半个新电脑。

Windows 这边，很多笔记本可以加内存、换硬盘、换电池，灵活性高多了。

有些软件没有 Mac 版

虽然大部分常用软件都有 Mac 版，但还是有一些"漏网之鱼"：

  • 某些工业软件、专业软件，只有 Windows 版。
  • 企业内网的某些客户端，只支持 Windows。
  • 网银、U 盾，Mac 上的支持一直很迷。

如果你只是写代码、办公、上网，Mac 完全够用。但只要你有一个"只有 Windows 能用"的软件，Mac 就会让你很痛苦。

我的结论

用了三个月 Mac，我的感受是：它不是完美的，但确实好用。

如果你问我会不会换回 Windows，我的答案是——看情况。

  • 如果只是写代码、办公、上网，我选 Mac。续航、触控板、稳定性，这些体验是 Windows 给不了的。
  • 如果需要玩游戏、用专业软件、经常外接各种设备，我还是会选 Windows。

工具没有绝对的好坏，只有适不适合。选你用着舒服的那个，就行。

你现在用的是 Mac 还是 Windows？为什么选它？评论区聊聊。
