OhMyShot：我做了个开源的 CleanShot X 替代品


我之前一直在用 CleanShot X，但对它的付费方案很不满意：从 v4 升级到 v5，必须一次买下 5 个席位，要价 50 美元，而我只有一台电脑，多出来的授权完全用不上。再加上它的 OCR 并不好用，识别率很低，我就决定自己搓一个，于是有了 OhMyShot。

项目是 10 月初开的坑，到现在界面和交互已经打磨得比较顺手，功能和算法也做得比较完善。我自己已经用它替代 CleanShot X 一个多月了，所以准备正式发布出来。

OhMyShot 是开源的，代码放在 GitHub 仓库，安装包可以从 OhMyShot 官网下载。

功能介绍

截图与标注

从普通的区域截图到完整的滚动截屏都有，其中滚动截屏的算法经过了我的特殊优化，现在可以在任何复杂情况下流畅并完整的拼接图片而不会出现画面撕裂这些问题。截完之后可以直接把截图 pin 在屏幕上做标注，也可以进入到编辑器做慢慢调整，箭头、打码、序号、气泡、聚光灯、水印这些工具都有，另外还有自动打码功能，算法会自动识别名字、mail 这类隐私信息。

OCR

前面说了，CleanShot X 的 OCR 我用着很烧心，所以这一块我花费了比较大的心思。识别默认全部在本地运行，使用本地模型和系统的 Accessibility API，可以直接读取现在正在截取软件的文字信息，而不只依赖于图片识别。截图后，图里的文字会被 OhMyShot 自动识别，可以直接复制。

在这种普通的使用场景之外，我还额外优化了代码截图的 OCR。系统自带的 Vision 会把单独占一行的 } 直接吞掉，还会把行号一起识别进来，复制出来的代码根本不能用（当时相当无语），这些问题现在都修好了。另外，图里如果有链接、邮箱、电话或二维码，会被单独列出来，点一下就能打开或者复制。

公式识别（输出 LaTeX）和表格识别需要另外安装本地模型包，用不到就不用下载。云端识别默认关闭，要用的话需要自己填写 API key。

贴图、取色与标尺

pin 在屏幕上的截图可以直接选中上面的文字；用来测量的标尺功能会自动吸附想测量的物体边缘，具体效果可以看下图。

录屏

在 OhMyShot 中，MP4 和 GIF 都能录，系统声音、麦克风和摄像头也都能录进去。录完可以进 Studio 剪辑，画面会自动跟随鼠标缩放；也可以直接选择 Studio mode 进行录制，会有算法自动进行放大和跟踪鼠标。现在这个优化得也很好了，录完后只用稍微调一下就是一个非常棒的 product 演示视频。另外，得益于 Apple 在 macOS 26 提供的新 API，还有类似英伟达即时重放的回溯录制功能，可以将最近 15s 发生的事情保存下来。

其他

截图历史功能中可以通过图片里的文字来搜索以前做的截图和视频。OhMyShot 也有云端分享功能，使用的是你自己的 S3、R2 或 WebDAV 服务。更重要的是，OhMyShot 还兼容 CleanShot X 的 URL 命令，所以以前的自动化脚本和工作流改个前缀就能继续用，这让所有的迁移变得更容易了。

系统要求

OhMyShot 的完整体验需要需要 macOS 26 或更高版本，并且只支持 Apple 芯片的 Mac。版本限制是因为前面提到的回溯录制功能（Keep last 15 seconds）用的是苹果从 macOS 26 开始才提供的回放 API，更早的系统无法使用则会被禁用这个功能, 。我正在准备自行实现这部分功能，以支持更多系统版本。

我平时在 macOS 27 beta 上使用，还没有在 macOS 26 的真机上测试过。如果你正在用 macOS 26，欢迎帮忙试一试。

安装

从官网下载页或 GitHub 下载 DMG，把应用拖进「应用程序」文件夹就行。安装包已经做过 Apple 的签名和公证。

想自己编译的话，先装好 Xcode 27 和 XcodeGen，然后执行：

git clone https://github.com/MMFoundation/OhMyShot.git
cd OhMyShot
Scripts/bootstrap.sh && Scripts/run.sh
