CentOS 目录穿梭

目录穿梭 = 使用 cd（Change Directory）在树形文件系统里切换目录；配套 pwd 看位置、ls 看内容，是运维最基础的导航能力 语法：cd [选项] 路径 cd 是 shell内置命令，不是外部程序，没有独立二进制文件

一、4个核心特殊符号（必背）

符号含义
/根目录，整个文件系统最顶层，所有目录都挂在它下面
.当前目录（cd . 无效果，一般在cp/ln里用）
..上一级（父目录）
~当前登录用户的家目录：root是/root，普通用户/home/用户名
-上一次所在目录（来回切换神器）

二、两大路径：绝对路径 vs 相对路径

✅ 绝对路径：以 / 开头，从根开始写，在哪执行都有效，脚本优先用

cd /etc/yum.repos.d
cd /var/log

✅ 相对路径：不以 / 开头，相对于你当前所在目录，适合临时穿梭

# 假设现在在 /var
cd log        # 进入 /var/log
cd ../etc     # 往上一层到/，再进/etc
cd ../..      # 连续向上退两级

快速判断：路径第一个字符是 / → 绝对路径；否则相对路径

三、cd 常用命令速查表

cd          # 直接回到家目录，等价 cd ~
cd ~        # 回家目录
cd ~zhangsan # 直接进入 zhangsan 用户的家目录
cd /         # 切到根
cd ..        # 上一级
cd ../..     # 上两级
cd -         # 在【当前目录 ↔ 上一个目录】来回横跳（非常高频）
cd .         # 留在原地，几乎不用

配套导航辅助命令（穿梭必备）

pwd          # print working directory，打印当前完整路径，防止迷路
ls           # 查看当前目录下有什么子目录
ls -a        # 看隐藏文件（.开头）

四、实操演示（跟着敲一遍）

# 1.登录默认在家目录
pwd          # root用户输出 /root
cd /var/log
pwd          # /var/log
cd ..
pwd          # /var
cd -         # 切回 /var/log
cd /etc/yum.repos.d
cd ../../home
pwd          # /home

五、Tab补全（穿梭效率核心）

输入路径一部分，按 Tab：

  • 能唯一匹配：自动补全目录名
  • 多个匹配：按两次Tab列出候选 > 例：cd /etc/yum.re 按Tab → 自动补成 cd /etc/yum.repos.d

六、cd 两个冷门选项（符号链接场景）

  • cd -L 默认：跟随软链接，路径显示为链接路径
  • cd -P：不跟随软链接，直接跳到真实物理路径
cd -P /linkdir

七、CentOS 常用目标目录（运维高频穿梭点）

/etc        配置文件
/var/log    日志
/var/lib    数据（mysql、redis）
/usr/local  源码软件安装目录
/home       普通用户家目录
/root       root家目录
/boot       启动文件
/dev        设备
/proc       内核虚拟文件（内存信息）

八、常见坑

  1. 目录名带空格：必须引号包裹 cd "my dir"
  2. 权限不足：cd: 权限不够，需要root或者加sudo（cd不能sudo！只能先sudo su切root）
  3. 目录不存在：报错 No such file or directory，检查拼写、Tab补全
  4. 区分大小写：Linux严格区分，CD /ETC 不行，必须小写
