让老音箱焕发新生：Home Assistant Connect AUX-2 首发体验


玩智能家居这几年，灯光、传感器和开关基本已经靠着 Matter 和 Home Assistant 打通了，唯独多房间音频（Multi-room Audio）还停留在各自为战的阶段。想让客厅的 HomePod、书房的 Sonos 和桌上的传统有源音箱同时放一首歌，往往会被不同品牌之间的生态围墙挡在门外。

为了填上这块拼图，Open Home Foundation（OHF）团队开发了全新的开源音频协议 Sendspin。在 Sendspin 1.0 标准临近发布的时刻，OHF 的商业伙伴 Nabu Casa 今天推出了全新的官方硬件来全力支持这一新的协议：Home Assistant Connect AUX-2。

你可以把它理解成一个专为 Home Assistant 和 Music Assistant 打造的音频接收盒。它的用法很纯粹，就是把家里的传统音箱或老功放接入 Home Assistant，配合 Music Assistant 实现全屋音乐同步。除了基础的无线串流，Nabu Casa 还给它塞进了 PoE 供电、模拟 / 光纤二合一输出和一堆创客扩展口，既照顾了想买来直接用的普通玩家，也给喜欢折腾 ESPHome 的极客留足了空间。

在使用了几周之后，我想聊聊这台小盒子能给国内玩家带来怎样的体验，以及它背后那个叫 Sendspin 的新协议到底解决了什么问题。

为什么有了 AirPlay，我们还需要 Sendspin？

聊硬件之前，绕不开 Connect AUX-2 的核心技术底座 Sendspin。这是由 OHF（也就是 Home Assistant 和 ESPHome 背后的非营利基金会）主导开发的开源多房间音频协议，目前已经推进到 1.0 RC1 阶段。

之所以放着现成的 AirPlay、Google Cast 和 Sonos 不用去「重造轮子」，是因为现有的商业协议太封闭了。之前我和 OHF 主席、Home Assistant 创始人 Paulus Schoutsen 聊起这个项目时他曾提到，如果你只是想自己写个程序接收音频流、做套音乐频谱灯效，或者加个自定义切歌旋钮，在封闭的商业协议里寸步难行。一年前，核心团队在芝加哥开完一场 Matter 闭门会后，在披萨店里拍板决定亲自下场，花了一年时间从头写出了这套免版税的开源协议。

和单纯的手机投屏不同，Sendspin 更像是一套跑在本地局域网里的音频协同系统。它通过在音频包里打上高精度时间戳并实时计算时钟漂移，让家里不同角落的设备先缓冲、再踩着同一个鼓点精准出声，并且能根据设备性能自动协商编码。更实用的是，依靠 Music Assistant 的桥接功能，你并不需要把家里的旧音箱全换掉，现成的 AirPlay 音箱、HomePod、Google Cast 甚至几十块钱的普通蓝牙音箱，都能被直接拉进同一个 Sendspin 群组里，和 AUX-2 一起同步放歌。

与此同时，Sendspin 在底层把发声、音源输入、切歌控制、封面显示和频谱可视化拆成了彼此独立的角色。这意味着你可以让 AUX-2 专心在电视柜上出声，让墙上的中控面板负责切歌和显示专辑封面，再让沙发底下的灯带通过 LedFx 读取音频节奏跟着音乐律动。虽然它目前还不支持杜比等家庭影院环绕声标准，但单就全屋音乐同步和声光联动来说，这套开源方案已经相当能打。

精致耐看，但离线难

回到 Connect AUX-2 本身。拆开包装的第一印象是，它终于不再是我之前体验同类方案的那种裸板，而是真正做出了消费级数码产品的精致感，纯白圆润的机身完美延续了 Nabu Casa 家族式的设计语言。

不过它的机身布局留了一个不大不小的槽点。由于接口被分散布置在了机身左右两侧，不管你把它摆在桌面还是音响架上，网线和音频线都得向左右两边劈叉伸出去，日常理线多少有点逼死强迫症。相比之前可以把线材优雅藏在身后的 Home Assistant Green，或者摆在桌上像个艺术摆件的 Connect ZBT-2，AUX-2 最好还是藏在音箱后面眼不见为净。

好在接口规格足够良心，尤其是那个模拟与数字光纤二合一的 3.5mm 输出口。你不需要进后台改任何开关，只要插上 3.5mm 转方口光纤线，机器就会自动识别并切换成数字光纤输出。我这几周一直拿它搭配宜家新款的 45 厘米 SOLSKYDD 音箱使用，实际听下来最推荐的也是光纤接法。它不仅声音底子更干净，还能彻底避开模拟音频线常见的接触不良和共地电流底噪；如果你手里有更高阶的独立 DAC 或传统功放，也能靠这个数字口无损接驳。

机身上的千兆网口同时支持 PoE 供电，一根网线就能搞定供电和音频传输，对于想把音箱装进吊顶或者弱电箱暗装的玩家来说非常友好。再往旁边看，USB 接口、串口以及国内创客很熟悉的 SEEED Studio Grove 扩展口一应俱全，看得出官方从一开始就没打算只把它当成一个单纯的音频接收器。 

半分钟无感配网，把折腾留给有需要的人

如果你家里有 PoE 交换机，AUX-2 的上手过程甚至可以用「无感」来形容。插上网线通电后，Home Assistant 几乎是秒弹新设备发现提示，一路点确认，大概半分钟就能跑完整个初始化流程；就算只用 Wi-Fi，打开手机上的 Home Assistant 伴侣应用多点几步也能轻松搞定。

让我觉得很舒服的一点是，普通用户买回来日常听歌，全程根本不需要去碰 ESPHome Builder。Home Assistant 会像管理普通智能插座一样，直接在后台接管它的设置和固件更新。比起以前在社区里自己找教程、改代码、编译刷固件的野生方案，官方硬件在省心程度上确实不在一个维度。而当你哪天手痒想折腾了，随时可以在 ESPHome 里接管设备，改编码、加传感器、或者接小屏幕，底层权限完全向你敞开。

听感与稳定性：能插网线就别用 Wi-Fi

真正把音乐放起来之后，你能明显感受到 Sendspin 协议目前还在打磨期的痕迹，以及里头那颗 ESP32-S3 芯片的性能限制。最直观的体验是，每次切歌或刚点下播放时，缓冲等待的时间会比预想中长一点；在拉群或者解散多房间音箱组合时，反应速度也要比苹果自家的 AirPlay 慢上半拍。不过音质上没得挑，能达到同价位的前端该有的水平。

但只要缓冲结束、音乐正式响起，它的同步表现就非常稳了。在我家里多台设备同时开播的压力测试下，各个房间的声音对齐得严丝合缝，连续挂着放几个小时也没有出现任何声道漂移或不同步的现象。

这里有个避坑经验是，能插网线就尽量别用 Wi-Fi。国内家用的 2.4GHz 无线环境非常拥挤，用 Wi-Fi 直接推流无损 FLAC 音乐时可能会遇到卡顿，而 ESP32-S3 本身老旧的无线模块更是放大了这个短板。不得不说没能赶上乐鑫新一代芯片大批量出货适配确实有些遗憾。

如果你摆音箱的地方实在没法拉网线，强烈建议进 ESPHome Builder 配置里把带宽占用更低的 Opus 编码打开，无线环境下的流畅度会有立竿见影的改善。只需要在配置文件里加上下面这几行代码就能生效（需要注意 Opus 专利编码仅供个人测试、非商业使用）：

media_source:
  - id: !remove sendspin_source
  - platform: sendspin
    id: sendspin_source
    task_stack_in_psram: true
    static_delay_adjustable: true
    codecs: [OPUS, FLAC, PCM]

音响架上的隐藏玩法：挂块歌词屏，或者当信号跳板

要是只拿来听歌，前面的光纤口和 PoE 其实已经值回票价了；如果你动手能力强，侧面的扩展口才是这台机器最好玩的地方。

比如那个 USB 接口，除了串口控制，还能直接用来做 Zigbee 或 Z-Wave 协调器的远程挂载。很多人的 Home Assistant 主机塞在弱电箱或者机柜深处，无线信号穿墙后效果差，这时候把协调器插在客厅电视柜的 AUX-2 上，就能顺理成章地把信号中心挪到房间正中央。目前 ZHA 的远程挂载功能还在实验阶段，我也挺期待官方后续能把这套玩法和自家的 Connect ZBT 系列硬件彻底打通，甚至直接当成 Thread 边界路由器来用。

旁边的 Grove 接口则直接连起了 SEEED Studio 庞大的模块化生态。我让 AI 按照 spec 生成驱动配置，给它插上了一块 Grove RGB LCD 字符屏，再套上自己用 拓竹打印机打出来的外壳，就能在音箱旁边实时滚动显示当前播放的歌名、专辑和进度条。

看着字符屏亮起的那一刻，复古味一下就出来了（这套配置代码和 3D 打印模型我已经传到了 GitHub 和 MakerWorld 上，如果你想复刻，记得切到 ESPHome Builder Beta 通道编译固件）。至于旁边的串口，官方也已经内置了 LG 和三星电视等设备的控制预设，顺手把客厅老电视拉进自动化里也很方便。

值不值得买？聊聊国内入手渠道与平替方案

Home Assistant Connect AUX-2 定价是 520 元（首发优惠价 450 元）。虽然海外社区里也有像 Apollo Automation 这样的小团队在做类似的第三方 ESP32 音频盒子，但一来国内根本买不到，二来算上高昂的转运邮费毫无性价比可言。好消息是，AUX-2 接下来会直接上架 SEEED Studio 在国内各大电商平台的官方店铺，不需要折腾海淘就能直接原价入手。

至于到底该怎么选，完全取决于你对音质和折腾程度的预期。如果你手里有不错的传统音箱或功放，想要省心地用上光纤输出、PoE 供电和原生固件维护，那直接等 SEEED Studio 上架 Connect AUX-2 就好。

如果你刚好还想在房间里加个本地语音助手，且对光纤输出没执念，同样国内能买到 Home Assistant Voice Preview Edition（海外定价 59 美元）其实更划算，它自带 3.5mm 音频口且原生支持 Sendspin，能顺带把语音控制一并解决了。

而要是你预算卡得很死、自己又熟门熟路喜欢刷机，去买一块两百块钱出头的 SEEED Studio reSpeaker Lite 开发板，自己动手刷入 ESPHome，同样能低成本跑起一套稳定的 Sendspin 播放器。配套外壳 MakerWorld 上一搜一大把，选个好看的装起来也不差。

Connect AUX-2 算得上是 Nabu Casa 迄今为止野心最大的一款硬件单品。它把原本门槛颇高的多房间音频同步技术，连同一系列 Home Assistant 硬件连接拓展能力，妥帖地装进了一个普通人半分钟就能配好即用的小盒子里。

随着针对 Sendspin 开发的创客套件陆续上市，Sendspin 1.0 标准也即将在年底正式发布。期待届时国内强大的音频硬件产业能够支撑起这个开源新秀，统一音频市场碎片化的生态。
