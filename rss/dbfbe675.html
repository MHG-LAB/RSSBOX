Apple 公布 Swift Student Challenge 安排

近日，Apple 公司公布了 2027 年的 Swift Student Challenge 学生挑战赛安排，作品提交期为 2027 年 2 月 8 日至 2 月 28 日，为期三周。今年起，学生可以提交为任意 Apple 平台开发的 app，包括 iOS、iPadOS、macOS、watchOS、tvOS 和 visionOS；往届则主要面向 iPhone 和 iPad。

参赛作品须为 Xcode app 或用 Swift Playground 制作的 app playground，以 ZIP 文件提交，大小不超过 500 MB，体验时长控制在三分钟以内。作品须由个人独立完成，不能依赖网络连接，须使用 Xcode 27 或 Swift Playground 4.7 及以上版本构建，内容须为英文。参赛者须为在校学生或符合条件的应届毕业生，并注册 Apple 开发者帐户，全职开发者不能参赛；中国大陆参赛者须年满 14 岁。

赛前，Apple 将举办三场线上「与 Apple 会面交流」活动：12 月 10 日讲解如何在 Xcode 中开始使用智能体编程，2027 年 1 月 14 日介绍挑战赛准备事项，2 月 4 日讲解如何讲述自己的 app。获奖者可获得一年 Apple 开发者计划会员资格和一份特别礼物，其中的杰出获奖者将受邀前往 Apple 园区参加 WWDC 2027。来源

微软 Auto SR 技术正式登场

11 月 10 日，微软公司宣布，旗下的 AI 超分辨率技术 Automatic Super Resolution 正式面向 Xbox Ally X、Xbox Ally X20 以及部分搭载 AMD 锐龙处理器的 Windows Copilot+ PC 推出。

与英伟达 DLSS、AMD FSR 等技术类似，Auto SR 是微软面向 Windows 游戏推出的 AI 超分技术，能够通过图像处理和 AI 算法提升游戏画面分辨率，在改善视觉效果的同时降低原生渲染负担。

微软今年 4 月起开始在 Xbox Ally X 上测试 Auto SR，当时该功能仅支持设备连接底座后的使用场景。此次正式推出后，玩家可以在手持设备、使用电池供电的情况下启用 Auto SR，同时新增对 1080p 游戏的支持。

微软此次还引入了全新的性能模式，将 Auto SR 帧率上限从此前约 60 至 75 FPS 提高至 120 FPS。玩家可以通过 Xbox Game Bar 在画质和性能两种模式之间切换，并在游戏运行过程中调整设置。

根据微软 DirectX 博客的信息，用户需要更新 Xbox Game Bar、安装最新 Windows 11 更新，并从 Microsoft Store 下载或更新 Auto Super Resolution Package。随后打开 Xbox Game Bar，进入「Widgets——Display——Graphics」，即可开启 Auto SR 的对应模式。来源

Arm 发布 Cortex-M42 处理器

11 月 10 日，Arm 公司发布公告，宣布推出 Cortex-M42 处理器，并将其纳入 Flexible Access 和 Total Access 两项技术授权计划。

定位方面，Cortex-M42 处理器主要面向对成本和芯片面积敏感的智能终端，目标为可穿戴设备、工业控制器等产品带来更强的机器学习与数字信号处理能力。架构方面，Cortex-M42 处理器采用基于 Armv8.1-M 架构，结合 Helium 技术与紧凑的 AHB 总线设计，方便芯片厂商升级现有的 Cortex-M4、Cortex-M33 微控制器方案。性能方面，相比较 Cortex-M33，最新 Cortex-M42 处理器向量计算能力最高可达三倍，向量计算能效最高可达两倍。

在实际应用中，新处理器可用于可穿戴设备的音频处理和关键词识别，也可承担工业设备的传感器分析与状态监测。

此次发布也扩充了 Arm 的技术授权组合。截至 2026 年 11 月，Flexible Access 拥有 319 家活跃成员，已促成超过 500 个独立流片项目；Total Access 拥有 60 家合作伙伴，累计支持超过 600 个项目。Arm 希望通过扩大技术获取渠道，推动更多设备在本地完成智能处理。来源

任天堂宣布「轻松登入」功能将下线

11 月 10 日，任天堂公司宣布，任天堂帐号（Nintendo Account）的「轻松登入」功能将于 2027 年 1 月 26 日 15:00（北京时间）下线。该功能下线后，任天堂将不再支持以 Google 或 Apple 帐号资料建立帐号，My Nintendo 点数计划中与谷歌帐号的连动任务亦会结束。

对于现在使用「轻松登入」的玩家，如果在到期日之后遇到登入画面，需使用与任天堂帐号配对的电子邮箱或 ID 登入，也可以使用通行密钥 (Passkey) 登入。来源

阿里推出 Qwen Code 1.0

11 月 11 日，阿里集团宣布推出 Qwen Code 1.0 版本，Qoder 与 Qwen Code 融合开源。

阿里把在 Qoder 中打磨的 Harness 能力融入 Qwen Code，随 Qwen Code 1.0 Preview 一起开放，为开发者提供可嵌入自身产品的 Agent 运行基础。

Qwen Code 1.0 从进程内的内存事件总线起步，沿着统一事件模型向分布式演进：将接入、调度与执行分层扩展，通过「手脑分离」让推理编排与工具执行独立管理。在保留既有入口与返回方式的基础上，从「一个进程、多个会话」走向「多个节点、更多会话」。

阿里方面表示，统一事件机制不仅连接入口与任务，也为能力扩展和资源管理建立清晰边界。各类处理单元围绕事件协作，模型、沙箱与外部扩展分别管理，让系统在承接更多任务时，更便于扩展能力、集中管控和控制成本。

Qwen Code 1.0 Preview 以独立分支开放，现有稳定分支继续保留。团队将沿着 1.0 的演进路线，持续完善功能覆盖与稳定性。来源
