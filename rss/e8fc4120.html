Linux 终端（Terminal）

终端 = 人机交互接口，Linux 一切操作底层都可以走终端；CentOS 里分物理终端、虚拟终端、伪终端，平时 SSH、图形界面打开的都是伪终端。

一、几个容易混淆概念（先分清）

  1. 终端 terminal：接收输入、输出文字的界面（硬件/软件）
  2. Shell：终端里的命令解释器（bash 最常用，CentOS 默认）
  3. 控制台 console：偏向本地物理终端，tty1~tty6
  4. TTY：终端设备文件统称
  5. PTY（pts） ：伪终端，SSH、图形终端窗口用的

一句话：终端是窗口，Shell 是里面跑的程序，你敲的命令交给 bash 解释执行

二、CentOS 终端类型

1. 虚拟控制台 TTY（本地，无图形）

CentOS7 开机默认图形界面，快捷键切换：

Ctrl + Alt + F1   图形界面
Ctrl + Alt + F2 ~ F6  字符终端 tty2~tty6

查看当前终端：

tty

输出示例：/dev/tty3 → 物理虚拟终端

2. 伪终端 PTS（最常用）

  • 图形界面点开的【终端】窗口
  • Xshell、MobaXterm、FinalShell SSH远程连接 设备文件：/dev/pts/0、/dev/pts/1，每开一个窗口编号+1
tty
# 输出：/dev/pts/0

查看所有登录终端：

who
# 或者 w（推荐，还能看负载、操作）
w

3. 串口终端 ttyS0（服务器IPMI、串口控制台，学习阶段很少碰）

三、终端命令行结构（提示符拆解）

CentOS 默认提示符：

[root@centos01 ~]#
[zhangsan@centos01 ~]$

逐个解析：

  • []：提示符分隔符号，不是必须
  • root：当前登录用户名
  • @：分隔符
  • centos01：主机名（hostname）
  • ~：当前所在目录，~ 代表家目录
    • root家目录：/root
    • 普通用户：/home/用户名
  • #：root超级管理员
  • $：普通用户

自定义提示符（PS1，可选了解）

echo $PS1

四、终端基础快捷键（高频，必记）

编辑光标

  • Ctrl + A 跳到行首
  • Ctrl + E 跳到行尾
  • Ctrl + U 清空光标前面所有字符
  • Ctrl + K 删除光标后面所有字符
  • Ctrl + W 往前删除一个单词
  • Ctrl + L 清屏（等价 clear）

进程控制

  • Ctrl + C 终止当前正在运行程序（强制中断）
  • Ctrl + Z 暂停程序，放到后台（bg/fg 调度）
  • Ctrl + D 退出终端 / 退出登录（exit）

历史命令

  • ↑ ↓ 上下翻看历史
  • !123 执行历史里第123条命令
  • !! 执行上一条命令
  • history 查看全部命令历史

五、终端输入输出：标准流（非常核心）

每个终端程序默认自带3个流：

名称文件描述符含义
stdin 标准输入0键盘输入
stdout 标准输出1正常打印信息
stderr 标准错误2报错信息

重定向符号：

# 输出覆盖
echo 123 > test.txt      # 标准输出写入文件，覆盖原有内容
# 追加写入
echo 456 >> test.txt
# 错误重定向
ls /abc 2> err.log
# 标准输出+错误一起写入
ls /abc &> all.log
# 管道 | ：把前一个命令的 stdout 交给后一个命令 stdin
ps aux | grep nginx

六、终端颜色、编码、字体

  • 编码：统一 UTF-8，防止中文乱码
echo $LANG
# 临时修改
export LANG=en_US.UTF-8
  • 颜色：由PS1、ls –color 控制，ls 不同文件类型颜色区分（目录/普通文件/链接/可执行）

七、终端会话（重点：断开SSH程序停止问题）

默认：SSH 终端关闭，里面跑的进程会收到 SIGHUP 信号，直接退出 解决工具：

  1. nohup：脱离终端运行
nohup python3 test.py &
  1. screen / tmux（生产最推荐，会话托管，断开重连还在） > tmux 适合学习、长期后台跑程序

简单 tmux 示例：

tmux new -s testrun   # 创建会话
# 运行程序，直接关闭SSH也不会停
# 重新连接后
tmux attach -s testrun

八、和终端相关常用命令汇总

tty        # 查看当前终端设备
who        # 查看所有登录终端
w          # 查看登录用户+终端+负载
whoami     # 我是谁
hostname   # 主机名
clear      # 清屏
reset      # 终端乱码花屏时重置终端
exit       # 退出终端

九、图形终端 vs 远程SSH终端区别

  1. 本地图形终端（gnome-terminal）：依赖图形桌面，只能本机
  2. SSH伪终端 pts：网络远程，运维主流，生产服务器基本无图形，只用这个
  3. TTY字符控制台：无图形，服务器本地黑屏模式
