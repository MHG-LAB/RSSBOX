网友分享苹果 iPhone Duo 小技巧：录入食指第二指节指纹，拿起手机即自然解锁

感谢IT之家网友 不一样的体验、软媒用户1942143 的线索投递！

IT之家 10 月 31 日消息，只要思想不滑坡，办法总比困难多。由于有人吐槽 Touch ID 不方便，Reddit 网友 @Wrznlmw 上周分享了一个关于苹果 iPhone Duo 的小技巧。

据 MacRumors 报道，在录入指纹时，用户可以将食指靠近第二指节的纹理录入系统，而非默认的指尖或指腹。这样一来，当你拿起手机时，手指关节自然接触侧边电源键，就能完成指纹识别和解锁。

苹果 iPhone Duo 的 Touch ID 指纹传感器集成在侧边电源键上。常规使用时，用户需要调整手指位置才能让指尖接触传感器，而录入食指第二指节附近的纹理后，可以利用日常握持手机时的自然接触动作完成识别。

这一技巧很快得到了其他用户的关注。有 Reddit 用户表示，将手指自然握持时接触传感器的部位录入指纹，可以减少拿起手机后额外调整手指的操作。

此前，iPhone Duo 使用 Touch ID 而非 Face ID 的设计曾引发讨论。苹果将指纹识别传感器集成在侧边按键中，部分媒体评测认为，Touch ID 相比 Face ID 增加了寻找传感器和放置手指的操作步骤。不过，也有用户表示，熟悉操作后，Touch ID 的解锁体验同样流畅。
