让 AI 在你我身旁，陪我把网页上的事做完


大家好，这是我第一次公开介绍自己做的一个工具：By Your Side，一个常驻在 Chrome 侧栏里的 AI 助手。

简单来说：它直接使用当前浏览器的页面和登录状态。你用一句话交代任务，它就能帮你阅读、点击和填写，也能把结果整理成页面上可交互的表格、图表或时间线。

我在网页上用 AI 时最烦的两件事

我每天大部分时间都在浏览器里：读英文资料、比参数、查一个人写过什么、填各种表。这些事很适合交给 AI，但实际用下来，总卡在两个地方。

第一件事，是来回搬运。 想让聊天机器人帮我看一个页面，我得先复制、截图、粘贴进对话框；它答完了，我再把答案搬回网页，自己动手去点、去填。AI 只负责中间那一段，两头的活还是我干。

第二件事，是重新登录。 现在也有能自己操作浏览器的 AI，但它们大多开的是另一个浏览器，或者跑在云端。我要的东西偏偏都在登录之后：后台、邮箱、网申系统。换一个浏览器，就要把扫码、短信、二次验证全部重来一遍。

还有一个让我不安的问题：就算它完成了任务，我也不知道执行过程中它点了什么、填了什么。

所以我想要一个「坐在旁边」的助手

我想要的是这样一个同伴：就在我正在用的浏览器里，看到的页面和我一样，登录状态也是同一份；我说一句，它去做；每一步我都看得见，随时可以拿回来。

这就是 By Your Side 名字的来历。下面用几段真实的录屏，说说它现在能做什么。

打开一篇英文维基，说一句「翻译成中文」，译文直接替换原文，排版和配图都留在原位。翻完我又说了句「标题改成紫色、正文换宋体」，它在同一页上改好，回答上方留一行「做了 2 步 · 耗时 15 秒」。

选中一段文字按 ⌘J，也能就地解释、翻译、接着追问，不用打开侧栏。

答案不只是文字，也可以是可交互的图表

很多时候，我问网页一个问题，真正想要的不是一大段文字。

在一个 Mac 机型对比页上，我问「这几款哪个适合我」，它把规格整理成一张表，点表头就能按续航排序。

在一页数据表上问「这些年有什么变化」，它画成一条折线，拖下面的滑块逐年看。

长文章可以理成一条时间线，点节点跳回原文对应的位置；也可以出几道题考考我，看自己读进去没有。

不只回答，它会替你动手

它用的是你的登录状态，所以能直接在网站上做事。在 DEV 上读到一篇喜欢的文章，我说「帮我关注这位作者」，它就去点了「Follow」，侧栏里一步一步写着它在做什么。

读到一个值得记的概念，说一句「记进笔记」，它把要点整理好存下来。

它也能跨好几个页面查资料。读完一篇讲 AI 和新人程序员的文章，我问「同行怎么评价这些观点」，它去读了另外几篇，把每个人的立场汇成一张表；我再让它用三四行中文总结，它把总结贴在了原文旁边。

找不到页面上的某个按钮或数字时，说一句「圈给我看」，它会在页面上把那个位置圈出来。

它停在你该做决定的地方

替人动手的工具，我最担心的不是报错，是它顺利做完了，做的却不是我想要的。

所以在关键的地方，它会停下来。下面这段，我把一张简历图拖进侧栏，让它照着填一份网申表。它填完 8 栏，停在「提交」按钮旁边，告诉我「我没点提交，你核对一下」。

目前的操作记录、接管和确认规则是这几条：

  • 每次动手都留痕。 回答上方写「做了 N 步 · 耗时」，展开能看到每一步点了什么、填了什么。
  • 随时能接管。 点「接管」，它立刻停手；你改完点「交还」，它先重读你改过的页面再接着做。
  • 发送前先问你。 发送确认覆盖点击发送按钮、多行输入框中的回车操作，以及通过页面脚本提交这几类路径。
  • 付款操作由你完成。 对识别为付款的操作，助手会阻止执行，即使你在对话里要求代付。这依赖对操作的识别，不代表能保证所有页面都没有漏判。

也要说清楚另一面：除了发送和付款，普通的点击、填写不会逐次弹窗确认，否则这个工具就没法用了。这一取舍也带来风险：网页内容中可能夹带恶意指令，诱导助手执行非预期操作，这类攻击叫作「间接提示词注入」。现阶段，建议只在可信的网站上使用自动操作，并留意执行过程；可信网站也不能完全排除这类风险。

同一件事，第二次不需要再反复纠错

这是我自己最喜欢的一点。第一次让它提取一个视频的字幕，它找不到页面上的字幕轨，试了几种办法，最后自己写了个脚本取下来，前后花了 5 分 42 秒。

第二次换一个新视频，它直接用上次学会的方法，12 秒就做完了。

它会把在某个网站上做成功的方法记下来，下次在同一个网站自动带上。你告诉它的偏好和资料也会记住，都能在「记忆」面板里查看、修改和删除。

隐私与数据：页面内容和密钥的去向

  • 任务需要的文字、页面内容或截图，只发给你自己在设置页连接的模型服务。
  • 模型密钥只存在这个浏览器里。
  • 这里的「记忆」指保存成功操作的方法，以及你主动告诉它的偏好和资料；网页正文或网页中要求「记住」的指令，不作为这类记忆保存，密码、验证码和卡号也不纳入记忆。
  • 诊断日志保存在本机，对密码、密钥和 Cookie 做脱敏处理；你可以在设置页导出或清空日志。

现阶段的局限与已知问题

  • 只能源码安装。 还没有上架应用商店。需要 Node.js 22.19 以上，自己构建、加载，再准备一家模型服务的密钥。
  • 只在 macOS + Chrome 上完整测过。 Edge、Brave、Arc 和 Windows、Linux 理论上能装，我没有逐一验证。当前版本不支持 Firefox 和 Safari。
  • 提示词注入与敏感输入风险仍然存在。 常规点击不逐次确认，网页中的恶意指令可能诱导助手执行非预期操作；页面脚本仍能读取密码框等输入区域的值，这一风险也尚未消除。
  • 模型偶尔会卡住。 主模型长时间没回应时，有时不会切到备用模型，这是我现在排第一的待修问题。
  • 语音还不稳。 实时语音在部分时段容易断开。

如果你想试试

如果你每天在浏览器里处理大量网页，手上已经有某家模型服务的密钥，也能接受一个还在快速变化的开发预览版，可以按下面的步骤安装体验。

git clone https://github.com/yishu-ziyu/By-Your-Side.git
cd By-Your-Side
npm ci && npm run build

然后打开 chrome://extensions，开启「开发者模式」，点「加载已解压的扩展程序」，选 extension/dist/；点工具栏的 By Your Side 图标打开侧栏，点「连接模型」填入密钥。

如果你在用 Claude Code、Codex 这类 AI 编程助手，也可以直接对它说：「请按 https://raw.githubusercontent.com/yishu-ziyu/By-Your-Side/main/docs/guides/install-for-agents.md 帮我安装 By Your Side。」

仓库地址：https://github.com/yishu-ziyu/By-Your-Side

它在哪里卡住了，或者做了你不想要的事，欢迎在 GitHub 开 Issue，这类反馈对我最有用。
