OpenAI 发布 GPT-6 Astra 模型

9 月 3 日，OpenAI 发布 GPT-6 Astra。该模型重点提升计算机操作、软件工程、网络安全、科学研究和专业工作流能力，并首次达到 OpenAI《准备度框架》（Preparedness Framework）设定的「关键级」门槛。

在智能体和计算机操作方面，GPT-6 Astra 能够连续执行多步骤任务，包括填写表单、操作网页和本地应用、管理日程、分析数据、构建和测试网站，以及制作文稿、表格和演示文稿。OpenAI 表示，Astra 可以在任务过程中调用上下文和外部工具，并根据反馈调整执行路径，用户无需将复杂任务拆分为多个步骤。

在软件工程和科研领域，OpenAI 称 Astra 是其目前能力最强的软件开发模型。官方测试显示，该模型在系统控制、浏览器交互、数学推理、科学研究和网络安全等多项测试中取得了此前模型的最高成绩。Astra 还可以调用专业软件完成数据处理、测试和验证。

网络安全能力是此次更新的重点。作为 OpenAI 首个达到《准备度框架》「关键级」标准的模型，Astra 在获得必要工具和访问权限后，可以在没有人工逐步指导的情况下，针对经过加固的现实系统寻找未知安全漏洞，并编写漏洞利用程序。在内部测试中，Astra 发现了两个此前未知的零日漏洞，并在高安全配置的浏览器和操作系统环境中构建了漏洞利用链。

针对潜在的滥用风险，OpenAI 对 Astra 采取了更严格的安全措施，包括隔离训练环境、限制网络访问权限和敏感工具调用、保护模型权重，以及进行持续监控和自动干预。发布初期，高级网络安全功能仅向受邀的安全测试人员开放，后续将通过「Daybreak Blue」等防御性研究计划扩大使用范围。

GPT-6 Astra 目前已向部分机构用户开放试用，计划在未来数日内向 ChatGPT Plus、Pro、Business 和 Enterprise 用户分批开放，并接入 OpenAI API 和 AWS。

发布会上，OpenAI 总裁 Greg Brockman 表示，Astra 可能成为通用人工智能（AGI）发展过程中的重要节点。他认为，未来回顾 AGI 的出现时间时，人们可能会将这一时期，甚至 GPT-6 Astra 本身视为关键节点，并称行业已经进入「AGI 时代」。不过，AGI 尚无统一的技术判定标准，这一说法主要代表 OpenAI 管理层对当前模型能力的判断。来源

Meta 发布 Muse Spark 1.3 模型

Meta Platforms 于 9 月 2 日发布新一代 AI 模型 Muse Spark 1.3，重点优化周期智能体工作流与编程能力。官方数据显示，相较于前代 Muse Spark 1.2，新模型减少了冗余的代码迭代，代码风格更加精简清晰，完成同等任务时的工具调用次数减少约 20%，Token 消耗降低 25%。

在多步骤任务与智能体协作方面，该模型支持在单一长线程中协同处理多项工作流，能够主动发现并修正规划缺口、跟踪任务进展，对复杂长指令中约束条件的保留能力也进一步提升；面对模糊指令时，模型会主动发起澄清提问，并在遇到阻碍或执行具有较大后果的操作前向用户寻求协助或确认。

此外，新版本增强了对自身能力和局限的判断，并提升了对对抗性输入和提示注入攻击的抵抗能力。Muse Spark 1.3 维持与前代相同的标准 API 定价：每 100 万输入 Token 费用为 1.25 美元，缓存命中为 0.15 美元，输出费用为 4.25 美元。来源

Anthropic 升级 Claude Code 及 Cowork

Anthropic 于 9 月 3 日升级了 Claude Desktop 的 Computer use 能力，为 Claude Cowork 和 Claude Code 引入了更完整的本地桌面操作功能。开启后，Claude 可直接识别屏幕画面，并通过点击、文本输入和界面导航操作本地软件。在 macOS 15 及以上系统中，系统默认以独立后台窗口运行这些任务，用户无需让出鼠标与键盘控制权，即可在电脑前同步处理其他事务。

根据官方说明，电脑控制设计上是后备方案，仅在任务无法通过连接器、浏览器或其他专用工具解决时才会调用。应用场景上，Claude Cowork 可借此完成本地文件整理、文档制作及多应用协作；Claude Code 则可用于启动测试原生软件、操控模拟器，或处理必须依赖图形界面（GUI）的开发流程。若需要直观观察操作过程，macOS 用户还可在客户端设置中将权限切换为直接接管屏幕的「完全控制」。

目前 Computer use 仍处于研究预览阶段，仅向 Claude Pro 和 Max 个人订阅用户开放，暂不支持 Team 及 Enterprise 企业套餐。任务执行期间电脑须保持唤醒状态，且桌面客户端不可关闭。系统适配方面，该功能现已支持 macOS 与 Windows。来源

微软调整 Xbox Cloud Gaming 商业模式

9 月 3 日，微软宣布将从 11 月起调整 Xbox Cloud Gaming 商业模式，首次允许未订阅 Xbox Game Pass 的玩家单独购买云游戏时长，同时取消现有 Game Pass 套餐中的无限云游戏权益，改为按月提供固定时长。

根据新方案，Xbox Game Pass Ultimate、Premium 和 Essential 用户每月将分别获得 15 小时、10 小时和 5 小时云游戏时长。用尽套餐内额度后，玩家可以通过 Xbox Store 购买额外的云游戏时长。微软表示，额外时长的具体价格、购买组合、可用游戏及市场范围将在 11 月正式实施前公布，不同地区的可用选项可能存在差异。

与此同时，Xbox Cloud Gaming 也将首次脱离 Game Pass 订阅独立提供。未订阅 Game Pass 的玩家可以直接购买云游戏时长，并在支持的设备上串流自己拥有、且已支持云端运行的游戏。这意味着，对于只偶尔使用云游戏、或不愿长期支付 Game Pass 月费的玩家，今后可以按实际使用时间付费。

微软表示，调整主要源于云游戏用户规模和平均使用时长持续增长，相应的服务器、带宽和基础设施成本也在上升。通过引入月度时长上限，公司可以在控制运营成本的同时继续投资服务稳定性和性能。微软预计，新限制大约会影响 4% 的 Game Pass 订阅用户。

云游戏仍是微软扩大 Xbox 硬件之外用户覆盖的重要手段。Xbox Cloud Gaming 可运行于 PC、手机、平板、智能电视及 Xbox 主机等设备，同时允许 Xbox One 用户通过云端运行部分仅面向 Xbox Series X|S 开发的游戏，从而无需立即升级新一代主机。

除新的按时付费模式外，微软还在探索更低门槛的免费方案。公司已于 7 月开始面向 Xbox Insider 测试广告支持的云游戏服务，玩家可以免费串流自己拥有的部分游戏，每次会话最长 1 小时，并在游戏开始前观看广告。微软希望通过订阅、按时付费和广告支持等多种模式，进一步扩大 Xbox Cloud Gaming 在移动设备和无主机玩家中的覆盖范围。来源

宏碁重启 Packard Bell 复古品牌

9 月 2 日，宏碁在德国柏林 IFA 2026 消费电子展上正式宣布重启旗下复古品牌 Packard Bell。Packard Bell 采用了全新视觉系统及「Tech it easy」品牌理念，正式将业务从个人电脑领域扩展至音频、移动通信与生活家电，首批产品将于今年秋季至第四季度陆续投放欧洲、中东和非洲市场。

宏碁首先推出了 14.5 英寸轻薄本 Packard Bell DotBook。该机主打网页浏览、影音播放与日常办公等轻量需求，并融入呼应早期经典设计的橙色外观元素。规格上，整机重量控制在 1.3kg 以内，采用 16:10 比例的 1920×1200 分辨率 IPS 屏幕；搭载英特尔 Core 3 N355 处理器，最高配置 16GB DDR4 内存与 512GB 存储，标称电池续航达 7 小时。该笔记本定于今年 11 月在中东和非洲市场上市，欧洲地区起售价为 499 欧元。

除 PC 业务外，Packard Bell 此次同步公布了多元化的「Dot」系列产品。首发阵容涵盖采用复古手提箱造型的 DotLoop 黑胶唱片机、DotTune 蓝牙音箱、DotLook 音频眼镜，以及支持蓝牙 6.0、续航约 40 小时的 DotBass 头戴式耳机；周边配件则包括 DotLine 4G 功能机、面向创作者的 DotShine 环形补光灯与 DotCombo 无线键鼠套装。上述多数产品将于 9 月起陆续上市。

此外，Packard Bell 还与初创企业 Steasy 合作进军家电市场，计划于 10 月推出售价 199 欧元的联网迷你蒸锅。宏碁表示，后续将充分调动自身在 EMEA 市场的渠道、仓储物流与售后支持网络，持续扩充 Packard Bell 的品类覆盖，推动该老牌品牌向综合生活科技生态转型。来源

Belkin 推出半固态电芯技术的移动电源

Belkin 推出首批采用 BoostSolid Cell 半固态电芯技术的移动电源，首发产品包括 UltraCharge Pro Slim Magnetic Power Bank 5K 和 UltraCharge Pro Power Bank 10K 两款，分别主打轻薄磁吸充电和高功率多设备供电。

BoostSolid Cell 在传统锂离子电池液态电解质基础上加入凝胶状材料，以提高电芯稳定性、改善温度控制，并提升单位体积内的能量利用效率。Belkin 宣称，与传统液态电芯相比，该技术可使电池寿命最长提升至约 3 倍，同时降低高温环境下性能波动的问题。

其中，UltraCharge Pro Slim Magnetic Power Bank 5K 配备 5000mAh 电池，采用金属机身和超薄设计，厚度约 8.8mm，支持最高 15W Qi2 磁吸无线充电，同时还可通过 USB-C 接口提供最高 22.5W 有线输出。Belkin 还加入双芯片温度保护机制，可持续监测设备温度。该产品售价 69.99 美元。

更高容量的 UltraCharge Pro Power Bank 10K 配备 10000mAh 电池，单设备通过 USB-C 充电时最高输出功率达到 60W，可用于手机、平板及部分笔记本电脑。机身提供两个 USB-C 和一个 USB-A 接口，最多可同时为三台设备供电，并配备显示屏，用于显示剩余电量、充电状态和实时输出功率。Belkin 表示，受益于 BoostSolid Cell 较高的能量密度，10K 型号相比常规 10000mAh 移动电源体积缩小约 27%。该产品同样采用双芯片温度保护，并以每秒 4 次的频率监控运行温度，售价为 89.99 美元。来源

微软承认 Windows 11 八月可选更新导致系统问题

微软于 9 月 1 日更新 Windows Release Health 公告，进一步确认 Windows 11 8 月更新引发的多项兼容性问题，其中包括自定义鼠标光标失效，以及部分 Arm 设备无法正常启动 Microsoft Teams 和新版 Outlook。与此同时，微软又于 9 月 2 日新增桌面背景异常问题，确认部分设备在更新后可能出现壁纸变黑、个性化设置无法恢复的情况。

其中，鼠标光标问题源自 8 月 27 日发布的 Windows 11 可选预览更新 KB5120998，主要影响 Windows 11 24H2 和 25H2。受影响用户可能遇到自定义鼠标指针被恢复为系统默认样式、光标动画间歇性失效，以及高 DPI 光标被替换为更大的白色光标等现象。微软调查后确认，该问题与非英语 Windows 安装中使用的代码组件有关，相关语言环境无法正常加载鼠标个性化设置，因此系统只能回退到默认值。由于故障发生在设置加载阶段，用户即使重新调整鼠标属性或手动恢复原有设置，也无法解决问题。

微软还于 9 月 2 日确认，部分 Windows 11 24H2 和 25H2 设备在安装该更新后，桌面背景可能直接变为纯黑色，幻灯片、对比度主题等设置也可能一并失效。与鼠标问题类似，受影响设备无法通过手动重新设置恢复正常状态。不过微软目前尚未公布该故障的具体成因，仅表示正在准备通过后续 Windows 更新提供修复。

此外，微软还确认了另一项针对 Arm 平台的兼容性问题。安装 8 月 11 日或之后发布的 Windows 安全更新 KB5121003 后，部分搭载 Arm 处理器的 Windows 11 设备，例如 Surface Pro 11 和 Surface Laptop 7，可能无法启动 Microsoft Teams 或新版 Outlook for Windows，应用也可能在启动后意外退出。经典版 Outlook、Word 和 Excel 等应用目前不受影响。针对 Arm 设备故障，微软已经提供临时缓解方案。用户可打开 Microsoft Store，进入下载与更新页面，并将 Auto Super Resolution Package 更新至 1.0.19.0 或更高版本。微软目前将该问题标记为「已缓解」，但仍需等待后续 Windows 更新修复问题。来源

Nvidia 收购 Hugging Face

英伟达于 9 月 3 日宣布，将以 129.303 亿美元收购开源 AI 开发者平台 Hugging Face，进一步扩大自身在开放模型、开发工具和 AI 开发者生态中的影响力。这也是英伟达历史上规模最大的收购交易之一。

根据交易方案，英伟达将向 Hugging Face 投资者支付约 119 亿美元，并另外提供最高 10 亿美元的股权留任计划。Hugging Face 目前已聚集超过 1800 万名开发者、研究人员和创作者，平台托管超过 300 万个 AI 模型、50 万个数据集和 100 万个应用，并被超过 20 万家企业用于发现、评估、定制和部署模型。

完成收购后，英伟达将获得全球 AI 开发者的重要入口。针对外界对平台中立性的担忧，英伟达 CEO 黄仁勋表示，Hugging Face 收购完成后仍将作为面向整个 AI 生态的开放平台运行，并继续支持不同厂商提供的开放模型、多云环境和多种硬件加速平台。开发者仍可自行选择所使用的模型、框架、云服务和计算硬件，使用 Hugging Face 不会被强制绑定英伟达 GPU。

英伟达认为，开放模型能够降低 AI 技术的使用门槛，使企业、研究机构和开发者无需从零训练模型，并根据具体任务选择更合适的技术方案。两家公司此前已经展开合作，英伟达也长期向 Hugging Face 提供模型、数据集和计算支持，目前已在该平台发布超过 500 个模型和 250 个开放数据集。来源

iOS 27 将新增 iPhone 接力功能

9 月 2 日，Apple iOS 27 曝光了一项名为「iPhone 接力」的新特性，允许两部手机共用同一个电话号码。该功能基于主从 eSIM 机制运行，用户可在「设置」的「蜂窝网络」中指定常用主设备与辅助设备；主设备保留原有主 eSIM，辅助设备则接收配套的辅助 eSIM，从而实现两台手机使用同一号码无缝切换。

在此模式下，所有蜂窝网络参数均由主设备统一管理，系统位置共享也会实时跟随当前正在通话或活跃的设备。相关运行机制由 MacRumors 论坛成员通过 Xcode 27 的 Device Hub 模拟器环境实机验证。该功能正式启用仍需电信运营商提供底层支持，预计美国 T-Mobile 与德国电信（Deutsche Telekom）有望成为首批适配的运营商。来源
