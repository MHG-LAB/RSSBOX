AutoHotkey V2 零基础快速入门 Part 5 游戏场景明暗阈值采集工具

本工具基于 AutoHotkey v2 开发，用于采集游戏内不同场景的画面亮度数据，自动计算正常画面与黑屏/淡出过场之间的亮度阈值，可用于游戏自动化的场景切换判定。工具支持可视化采样点定位，可直观调整采集位置，输出详细的统计分析与候选阈值。

一、热键功能一览

热键功能说明
F6显示 / 隐藏五个采样点标记
F7重新捕获当前活动窗口，并刷新采样点位置
F8开始 / 停止亮度采集
F9标记当前为「第一场景正常画面」
F10标记当前为「淡出/黑屏过场」
F11标记当前为「第二场景正常画面」
F12查看五个采样点的详细信息（坐标、比例、颜色、亮度）
Esc退出脚本

; ============================================================
; RGB转感知亮度
; ============================================================
ColorToBrightness(Color) &#123;
    Red := (Color >> 16) & 0xFF
    Green := (Color >> 8) & 0xFF
    Blue := Color & 0xFF
    Brightness := Round(
        Red * 0.2126
        + Green * 0.7152
        + Blue * 0.0722,
        2
    )
    return Brightness
&#125;

三、标准使用流程

  1. 运行脚本 双击 .ahk 文件启动，弹出功能说明窗口，确认后关闭即可。

  2. 捕获游戏窗口 切换到目标游戏窗口，按下 F7，屏幕上会显示 P1~P5 五个红色标记方块，方块中心即为实际采样坐标。

  3. 调整采样位置 观察红色标记是否落在目标采集区域：

    • 位置合适：按 F6 可隐藏标记，避免干扰画面
    • 位置不合适：参考下文「采样点调整方法」修改参数后，重新按 F7 刷新

  4. 启动正式采集 按下 F8 启动采集，采样点标记会自动隐藏，避免污染采集结果。左上角会实时显示当前阶段、平均亮度、最低/最高亮度。

  5. 分阶段标记场景

    • 第一场景画面正常稳定时：按 F9
    • 场景切换、淡出/黑屏过程中：按 F10
    • 第二场景完全显示、画面稳定后：按 F11

  6. 停止并查看结果 再次按下 F8 停止采集，自动弹出结果窗口，包含：

    • 三个阶段的亮度范围（样本数、最低、最高、平均）
    • 阈值分析与候选阈值建议
    • CSV 日志文件路径

  7. 查看采样点详情（可选） 按下 F12 可查看每个采样点的屏幕坐标、相对比例、颜色值、亮度值。

四、采样点位置调整方法

工具采用窗口相对比例定位采样点，调整时只需修改脚本顶部的 SamplePointConfigs 配置数组，无需改动核心代码。

参数说明

  • XRatio：水平方向比例，0.00 = 窗口最左侧，1.00 = 窗口最右侧
  • YRatio：垂直方向比例，0.00 = 窗口最顶部，1.00 = 窗口最底部
  • Description：采样点备注，仅用于展示

调整示例

  • 中间点 P3 向下移动：将 YRatio: 0.40 改为 YRatio: 0.55
  • 左上点 P1 向中间靠拢：将 XRatio: 0.20 改为 XRatio: 0.30

修改完成后保存脚本，按 F7 即可刷新标记位置。

五、核心功能说明

1. 亮度计算

采用人眼感知加权亮度公式：

亮度 = 红×0.2126 + 绿×0.7152 + 蓝×0.0722

亮度范围 0~255，更符合真实视觉感受。

2. 阈值判定逻辑

采集完成后自动分析两组数据分布：

  • 可分离区间：黑屏最高亮度 < 正常画面最低亮度

    • 输出候选阈值（取两者中间值）
    • 亮度低于阈值判定为偏暗，高于判定为偏亮
    • 同时给出自动化优化建议

  • 数据重叠：黑屏最高亮度 ≥ 正常画面最低亮度

    • 提示重叠量，不建议使用单一固定阈值
    • 给出优化方向：调整采样点、避开UI/角色、增加连续帧判断、双阈值方案等

3. 数据日志

所有采样数据自动保存为 brightness_log.csv（脚本同目录），包含时间戳、阶段、五个点亮度值、平均/最低/最高亮度，可用于后续二次分析。

4. 防污染设计

正式采集开始时，采样点标记会自动隐藏，避免红色标记被像素读取到，保证采集数据准确。

💡 建议每个阶段保持采集 3~5 秒，足够的样本量会让阈值计算更准确；尽量避开角色、动态UI、火焰等亮度频繁变化的区域。
