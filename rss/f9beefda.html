为 Mac 而生：Markdown 编辑器 Lettera 现已开启公测


大家好，在之前的推送里我们曾提到一个神秘新项目，也预告过它会很快与大家见面，经过了忙碌又充满期待的几个月后，今天我们终于可以宣布：Lettera 公测版正式上线啦！

要介绍 Lettera ，就不得不提起 Panda，一款我们为熊掌记 2.0 全新设计并单独测试的编辑器，也是 Lettera 的前身。在测试期间，很多用户来询问 Panda 能否作为独立应用发布。于是， Lettera 来了。

Lettera 介绍

Lettera 是一款 macOS 原生的轻量级 Markdown 编辑器。无论是快速撰写博客草稿，还是构建完整的技术文档系统，都能轻松胜任，它为所有写作者、研究人员、开发者，以及有任何文档处理需求的人而打造。

Lettera 能适应各种使用场景。你可以打开单个文件进行阅读和编辑，或者打开一个文件夹作为写作工作区：


以文件夹为工作区： 默认情况下，Lettera 会打开 iCloud 中的 Lettera 文件夹。如果想打开 Mac 上的其他文件夹，可前往菜单栏「文件 > 打开…」，或直接把访达中的任意文件夹拖放到程序坞的 Lettera 图标上。侧边栏会完整显示该文件夹原有的目录结构，与访达中保持一致。点击任意 Markdown 文件，即可在编辑器中打开并开始编辑。

单个文件编辑：你也可以在 Lettera 中打开Mac 上的任意 Markdown 文件，立即进入编辑模式开始创作。

功能速览

  • 所见即所得的 Markdown 写作体验： Lettera 遵循 CommonMark 标准，支持实时渲染。不在编辑状态时，Markdown 语法会自动隐藏，让你可以在同一界面上写作和预览。此外，BIU 格式工具栏可帮助你快速调整文本样式。
  • 丰富的格式支持：表格、引用、列表、代码块、内联图片与附件，以及基于 Mathjax 的数学公式等等。
  • 轻松分享与导出：文本内容可复制为纯文本、富文本、Markdown 或 HTML 格式；需发送工作成果时，还能导出为 PDF、JPG、ePub 等多种格式。
  • 便捷的文件与文件夹管理：无需离开应用即可在侧边栏中直接管理文件和文件夹；支持多标签页打开文件，方便在同一界面处理多个文档；图片文件可直接在编辑器内预览。
  • 目录：通过完整的文档大纲快速导航，一键跳转到任意章节。

如何安装

点击 加入测试 获取 Testflight 链接，在 Mac 打开即可下载 Lettera 公测版。

注意：测试版暂不支持中文。
