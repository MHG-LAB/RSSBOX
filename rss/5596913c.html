Travel Planner — 智能旅行行程规划助手

"每次旅行最累的不是走路，而是出发前的攻略制作。" —— 每一个旅行者的心声

你是否经历过这样的场景：兴致勃勃地决定去某个城市旅行，打开几十个浏览器标签页，翻遍小红书、马蜂窝、大众点评，三天后行程表还是一片空白？

传统旅行规划的五大痛点

📰 信息碎片化

景点、美食、住宿、交通散落在不同平台，光是汇总就耗掉半天。小红书说这个好，大众点评说那个好，到底该信谁？

🗺️ 路线不会排

景点之间多远？先去哪个后去哪个？一天能玩几个地方？全靠感觉拍脑袋，结果不是赶路就是浪费半天。

🎫 门票踩坑

到了景区门口才发现要提前三天预约，或者官方公众号早已约满。白跑一趟，心情全毁。

🍽️ 选餐馆纠结

人均多少？在景点附近吗？合不合口味？有没有备选？打开 App 搜了半小时，最后还是进了景区门口的快餐店。

💰 预算算不清

油费多少？过路费？住宿多少？门票加起来多少？旅行结束才发现超支严重，回来吃土一个月。

Travel Planner Skill 怎么解决？

Travel Planner 是一个运行在 Trae Work 中的 AI 技能（Skill），它将整个旅行规划流程自动化：从搜索目的地信息、查询门票预约方式、规划每日时间轴，到生成景点实景图、推荐真实餐馆、计算全程预算，最终输出一份精美的 HTML 旅行攻略。你只需要告诉它"从哪出发、去哪玩、几天、预算多少"，剩下的全部交给 AI。

  • 🔍 一键全网搜索：自动并行搜索景点、美食、住宿、交通、门票信息，从碎片化信息中提取真实有效的内容，不再手动翻几十个标签页。
  • ⏰ 智能逐日时间轴：按地理位置就近原则排布景点，每天 2-3 个核心景点，附带每段路程的距离、交通方式和导航链接，精确到小时级。
  • 🎟️ 门票预约全覆盖：为每个景区标注门票价格、是否需提前预约、预约渠道（公众号/美团/携程）、当天能否买票。再也不白跑一趟。
  • 🍲 真实餐馆推荐：每餐推荐具体店名+地址+招牌菜+人均价格，并根据你的餐饮预算自动筛选价格合适的餐厅，还附备选店和距离导航。
  • 📸 AI 景点实景图：为每个景点自动生成实景照片，不用再到处搜图片，攻略自带视觉预览，所见即所往。
  • 🗺️ 百度地图导航集成：住宿→景点→餐馆之间每一段都有距离、出行方式和一键导航链接。自驾游还能生成路线总览地图，含油费、过路费估算。
  • 💰 全程预算明细：油费、过路费、住宿、门票、餐饮、停车费分类汇总，一目了然。出行前就知道大概花多少，心中有数不超支。

如何使用

Travel Planner 支持两种使用方式，推荐使用 方式一（AI 全自动） 获得完整体验。

方式一：在 Trae Work 中调用（推荐，全自动）

  1. 安装 Skill：将 travel-planner 目录放入项目的 .trae/skills/ 目录下，或确保 Skill 已在 Trae Work 中注册。
  2. 直接输入需求：在 Trae Work 对话中用自然语言描述你的旅行计划即可，AI 会自动识别并调用 Skill。
  3. 确认参数：AI 会将识别到的出发地、目的地、天数、预算、出行方式等汇总成表格让你确认，缺少的关键信息会主动询问。
  4. 自动执行全流程：AI 自动执行 → 搜索景点 → 查门票 → 排时间轴 → 找餐馆 → 生成景点图片 → 生成导航链接 → 汇总预算。
  5. 获取 HTML 攻略：最终输出一个自包含的 HTML 文件 + 景点图片目录，浏览器打开即可使用。
# 示例：直接在 Trae Work 对话中输入


我从武汉出发去威海，12天自驾游，2人夫妻，每餐预算100元，
偏好自然风光和美食，9月25日出发，帮我规划完整行程

方式二：本地 Python 脚本（生成模板，手动填充）

如果没有 AI 工具，也可以用附带的 Python 脚本生成 HTML 模板框架，然后手动填充信息。

# 进入 skill 目录
cd travel-planner


# 运行脚本，按提示输入参数
python travel-planner.py


# 脚本会引导你输入：
# - 出发地、目的地、天数
# - 预算级别、偏好、出行日期
# - 出行方式（自驾/公共交通）
# - 每日最大驾驶小时（自驾时）
# - 出行人数及关系


# 输出：
# - travel-itinerary-&#123;destination&#125;.html（带占位符的模板）
# - travel-images/（图片目录）


# 之后手动搜索替换”待填写”内容，
# 或将模板交给 AI 工具自动补全

支持的全部参数

参数必填说明
origin是出发城市
destination是目的地城市
days否天数，默认 3 天
budget否budget / moderate / luxury，默认 moderate
dining_budget是每餐全体成员合计预算，如"2人每餐100元"
preferences否偏好：nature, food, culture, shopping 等
travel_dates否出行日期或季节
travel_mode否self-driving / public / mixed，默认 public
daily_drive_limit否自驾每日最大驾驶小时，默认 4 小时
travelers否人数及关系，如"2人情侣"、"3口之家"
