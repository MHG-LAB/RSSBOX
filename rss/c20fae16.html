你还需要 Terminal 吗？我为什么选择 Kaku？


AI 会影响生活中的细枝末节

事情的起因是上周看到图拉鼎不用终端了，现在连 vscode 都扔垃圾桶了，AI 带来的变化多端在这一刻具像化了，不像是自媒体或者技术 KOL 们颠覆业界、重新定义“编程”的宏大叙事，从日常工作流中被剔除的 terminal 和 vscode 才是更能让我感同身受的 AI moment。

我自己是长达十年的命令行用户，从入行嵌入式使用串口，到 Linux bash shell，Android adb，Mac zsh，命令行一直是我认为程序员很 cool 的一个象征，《命运石之门》里的Daru、《某科学的超电磁炮》中的初春、《良医》中的Lea，都是我觉得很酷的 hacker/engineer，所以我一直对命令行情有独钟，也体验过很多不同的终端产品，因而我也从来没想过要不要完全不使用终端这个问题，即便看到图拉鼎不用终端我也只是惊叹一下然后就翻篇了。

但偏偏在看到废纸篓里的 vscode 时，我脑子里突然产生了“AI 的影响真是面面俱到”的想法。它不单是降低了编程门槛、放大个人能力、加速科技进程，对于日常工作和生活中的一些零零碎碎、边边角角都有影响，细微处渗透到你解锁电脑的第一步是打开浏览器还是 agent，以及你和工作的交互入口还是否还是传统的命令行与vscode。

经过一番思考，我发现 vscode 我真的可以不用，但终端不行，我完全离不开终端，

一是内存占用问题，我的 MacBook Air 不支持我高强度通过 GUI 使用 Agent，尤其是我还经常开十几个 Chrome 标签页；

二是我实际感受客户端多窗口切换没有终端方便，无论是在效率还是美观方面；

三是对命令行的一点点执念，偶尔的还会在看到满屏指令时幻想自己是石之门里的Daru（其实更喜欢初春）。

但说到 VS Code 情况就不一样了，好像上次打开还是一两个月之前？删了删了，等我决定不再用终端的时候对我来说才是一个巨大的改变hhhh.

值得一提的是，我一直感觉 GUI 的多窗口使用体验没有在 TUI 中好，界面很容易乱，大小不一、堆叠混乱，尤其是窗口多的时候，即便在 Mac 四指上滑使用多窗口视图也很难快速切换到自己想要的窗口。而使用终端就没有这个烦恼，统一的风格和布局，在一个大窗口里放置有限的分隔，通常一个项目最多开4个小窗口，完全可以放在一个会话/屏幕内，多个项目使用多个tab，通过快捷键或者点击切换都很方便，这么看来似乎和DHH的偏好很契合，难道Omarchy才是我的理想OS？？？（慎重、慎重。。。

除了观感上的区别，在性能和内存占用上，我依然推崇 TUI，毕竟刨掉 UI 壳确实省不少内存，我想目前阶段每个 agent 开发者都不会允许自己的电脑只跑一个主agent+几个subagent，这显然无法充分压榨自己的 coding plan，不把 weekly limits 用完应该是睡不着觉的。当然受限于笔记本性能而选择终端是我的问题，agent 是无辜的，图大显然也没有这个顾虑，等我什么时候通过业余产品有收入了会升级一下设备并严肃思考如何在“一点执念”和效能上做权衡。

非严肃 Terminal 主观评测与 Kaku

目前我的主力终端是优雅至极的 Kaku 选手，一款轻量、快速、AI 友好的基于 WezTerm 深度定制的终端，出自 @tw93 之手（这就是口碑.gif）。

在接触 Kaku 之前，我使用了大概两年多的 iTerm2，它的优点我现在能想到的就是成熟、成熟、成熟，再就想不到了，额外的印象就是偶尔的卡顿，但也不确定就是它的问题。当初倒也没有很想换，我时不时地会改改ohmyzsh的配置和p10k主题，就是觉得无聊想寻觅看看有没有有意思的新的终端产品，然后自然而然 Kaku 进入了视野。

它的第一优点很明显，开箱即用，不用做什么配置，主题风格对胃口，字体好看，配置页清晰明了，非常有限的配置项，刚好能满足我的日常使用和轻度diy需求，以及我真的太喜欢纸质主题了，这就是纸质书读者、墨水屏爱好者、浅色主题倾向性的福音。

这种丝滑上手的体验，有点像我之前从小米手机换成iphone时的手感上的那种爽感，看上去的区别和盘起来的区别是不一样的，后者更让人想去细品。第一天使用下来，我就知道 iTerm2 可以卸载了。你很难拒绝一款刚刚好适配你的产品，iTerm2 没毛病，它更强大、更普适、DIY 空间更大、有庞大的生态和解决方案，但就是因为太“大”了，Warp 也很好，但那不是我想要的好，Warp 比 iTerm2 和 Kaku 都更加 AI Native，但可能是我还没有那么的 AI Native，我目前也接受不了注册登陆使用和block的类 Notion 操作交互。

iTerm2 好比优衣库 Levi's，Warp 好比耐克始祖鸟，Kaku 好比山本耀司或者小众精品定制裁缝店里的成衣款？😂不知道这么形容有没有冒犯到，但给我体感是这样的，它的定制成衣穿我身上刚好。

目前高强度使用两个月了吧，每天在里面猛蹬 cc 和 codex，没有出现过使用ChatGPT 客户端时频发的界面卡顿现象，偶然间发现小 bug 还能提个 pr，这也是另一项优势了，给 iTerm2 提 pr 估计得等猴年马月，Warp 干脆不支持。

对了，搞笑的是我初期过于沉迷好看的界面和流畅的交互，居然忘了试试 Kaku 介绍中的"AI friendly"，国庆的时候一次偶然使用 command+L 打开了 AI 对话界面，原本是打算在typora中打开大纲的，但是忘记把窗口焦点切到主屏幕了，意外触发了放在扩展屏的 Kaku AI，然后简单寒暄一下就可以用了。

这个一键呼出快捷对话的交互体验，我感觉比 Claude 的 /btw 方便一些，和 Howler 有异曲同工之妙🤣。初次之外，终端主界面支持在底部显示 plan 的用量，在达到25%/10%/5%会有一行预警提示，这些细节处的设计很巧，够用且不觉打扰。

美中不足也是有的，比如右键菜单缺少 Open in finder 选项，因为 Agent 经常会在 /tmp 等路径生成一些文件，emmm...可以考虑开个 pr 看看。

洋洋洒洒写了些，算是梳理一下对于 Terminal 的些许看法，顺带推荐一下 Kaku。我觉得深度定制化会是 AI 加持下一个很有趣的产品趋势，以前受限于生产力瓶颈，很多产品希望通过做的大而全去满足更多人的需求，但现在百花齐放匹配上众口难调，完全可以更聚焦于深度而非广度，Kaku 就是一个很好的案例。这对独立开发者或者业余开发者来说，都是挺有搞头的。

以上。
