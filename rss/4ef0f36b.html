1. 你将得到什么

读完这一篇，你能拿走四样东西：

  1. 一张分组地图：9 个实时端点按「单票实时 / 全市场快照 / 历史逐笔」分成 3 组；
  2. 一次跑通的代码：/hs/real/ssjy 拿单票实时，/hs/real/five 拿五档盘口；
  3. 五档盘口的解法：买卖五档是嵌套数组，要按档位展开；
  4. 三个真实踩坑点，都是第一次用几乎一定会踩的。

代码全部自包含，复制进 .py 直接能跑，不依赖 numpy / pandas。

2. 本篇取数约定

  • 全部接口都是 GET + query 参数，token 放在查询串里（?token=xxx）；
  • 统一基址 https://api.zhituapi.com；
  • 代码块里的 你的token 是占位符，换成你的 token 即可；
  • 所有接口路径均取自官方已验证文档，跨篇零重复。

4. 核心模板函数

import requests, time


BASE = “https://api.zhituapi.com"
TOKEN = “你的token”


def _hit_key(d, *cands, default=None):
    if not isinstance(d, dict):
        return default
    for c in cands:
        if c in d and d[c] not in (None, “”, “-“, “null”):
            return d[c]
    low = &#123;str(k).lower(): v for k, v in d.items()&#125;
    for c in cands:
        v = low.get(str(c).lower())
        if v not in (None, “”, “-“, “null”):
            return v
    return default


def _get(path, params=None, timeout=10, retries=2, backoff=0.6, default=None):
    q = &#123;“token”: TOKEN&#125;
    if params:
        q.update(params)
    last = “”
    for i in range(retries + 1):
        try:
            r = requests.get(BASE + path, params=q, timeout=timeout)
            if r.status_code == 200:
                try:
                    return r.json()
                except ValueError:
                    return default
            last = “HTTP %s %s” % (r.status_code, (r.text or “”).strip()[:80])
        except Exception as e:
            last = “%s: %s” % (type(e).name, e)
        if i < retries:
            time.sleep(backoff * (i + 1))
    return &#123;“_error”: last&#125;

def five_levels(code):
    d = fetch_five(code)
    if isinstance(d, dict) and “_error” in d:
        return None, d[“_error”]
    # 买卖五档通常是 bids/asks 嵌套数组
    bids = _hit_key(d, “bids”, “buy”, “委买”, default=[])
    asks = _hit_key(d, “asks”, “sell”, “委卖”, default=[])
    return &#123;“bids”: bids[:5], “asks”: asks[:5]&#125;, None

5. 跑通示例

把上面的代码复制到本地，填入你的 token 即可直接运行：传入股票代码，five_levels 展开买卖五档，fetch_trade 还能拉指定日期的逐笔回放（各字段含义见前文各小节）。

6. 坑与注意事项

坑 1：实时接口盘中才有数据，盘后返回空或昨收快照。 /hs/real/ssjy、/hs/real/five 都是盘中实时推送，收盘后要么返回空、要么返回昨收静态值。做盘后回测别直接调实时接口，要用 /hs/real/zbjy/{日期} 的盘后逐笔回放，或用历史行情接口。

坑 2：五档盘口是嵌套数组，档位顺序别反。 /hs/real/five 返回 bids（买盘，价格从低到高）和 asks（卖盘，价格从高到低），每档是 [档位, 价格, 数量]。做买卖价差要确认买一在 bids[0]、卖一在 asks[0]，别把数组顺序搞反导致价差算负。

坑 3：全市场快照量大，别每次全量拉。 /hs/public/realall 一次返回全市场几千只股票的实时快照，数据量大、频率高的话容易触发限频。做全市场监控建议用 /hs/custom/realall（自选股子集）按需拉，别无脑全量轮询。
