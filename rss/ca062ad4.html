Mac 也能用 Wallpaper Engine 壁纸了


利益相关：我是 WallpaperMachine 的开发者之一。

用过 Windows 的朋友大概都知道 Wallpaper Engine：Steam 上十几块钱，创意工坊里有海量动态壁纸，有会跟着音乐跳的，有能用鼠标互动的，还有整套 3D 场景。换到 Mac 以后，我最想念的就是它。

Mac 上当然也有动态壁纸 App，但大多只能放视频，或者要你去它自己的壁纸库里重新找。我已经在创意工坊攒了一堆壁纸，就想让它们在 Mac 上动起来，尤其是那些"场景"类的，不是一段视频能替代的。

找了一圈没找到满意的，于是我们几个人自己做了一个：WallpaperMachine。

宣传视频：https://pub-5adbf40090d94bfca6163d39fe1521ff.r2.dev/WallpaperMachine-Teaser-1440p60.mp4

它能做什么

三种壁纸都能放。 Wallpaper Engine 的场景（Scene）、视频（Video）和网页（Web）壁纸都支持。场景壁纸是最难的，也是我们花时间最多的地方。

创意工坊直接内置。 在 App 里就能浏览创意工坊，不登录也能逛。看中了直接下载，可以多个任务一起下（下载需要一个拥有 Wallpaper Engine 的 Steam 账号）。已经有本地壁纸的话，也可以直接导入文件夹，只复制，不动原文件。

壁纸参数随便调。 壁纸作者留的所有选项（颜色、速度、开关之类）都能在 App 里改，每张壁纸单独记住。

多显示器分开设置。 每块屏幕可以放不同的壁纸，也可以镜像；缩放、帧率、音量都能分别调。

跟着音乐动。 打开音频响应后，那些会随音乐律动的壁纸会跟着 Mac 正在播放的声音动起来。带"正在播放"信息的音乐类壁纸，还能显示当前歌曲和封面。

锁屏也能动。 视频和场景壁纸可以放到锁屏上（实验性功能，默认关闭）。

不偷偷耗电。 屏幕被窗口挡住时会暂停这块屏幕的壁纸，睡眠或锁屏时全部暂停。用电池时可以选择暂停，或者降低渲染分辨率和帧率。

看起来像 Mac App。 跟随系统的深浅色和强调色，界面支持简体中文。

不想装也能先看看：官网上有一个跑在演示壁纸库上的同款界面 → https://www.wallpapermachine.app/#app

它是怎么做出来的

给好奇的朋友简单说一下：

  • 外壳是 Swift / AppKit，控制面板是跑在 WKWebView 里的网页
  • 渲染核心用 Rust 写，负责显示器、壁纸窗口、视频解码和音频采集，通过 uniffi 和 Swift 通信
  • 场景壁纸的绘制基于开源的 open-wallpaper-engine（C++），通过 MoltenVK 把 Vulkan 跑在 Metal 上；我们也在写一个原生 Metal 渲染器，可以在设置里打开试试
  • 锁屏壁纸是一个沙盒化的 ExtensionKit 扩展

最难的部分是场景兼容性。Wallpaper Engine 的特效着色器是按 Windows 的习惯写的，很多壁纸还依赖一些没有文档的行为，所以目前并不是每张都能完美显示。

目前的限制

实话实说，它还在早期：

  • 需要 macOS 26 Tahoe 和 Apple Silicon（M1 及以上），不支持 Intel Mac
  • 还没有经过 Apple 公证，第一次打开需要去「系统设置 → 隐私与安全性」里点「仍要打开」
  • 不是每张壁纸都能正常显示，Application 类壁纸完全不支持。遇到显示问题，App 里有一个按钮可以一键打开预填好信息的 GitHub issue
  • 场景壁纸需要用到你自己已购 Wallpaper Engine 里的资源，所以它不能替代购买 Wallpaper Engine

要钱吗？

不要。 源码以 GPL 完整开源，App 本身免费。

如果想支持一下，可以成为 Supporter（一次性 $4.99），会出现在官网和 README 的赞助墙上，并获得优先支持。Supporter 不解锁任何功能，买没买，App 都完全一样。国内 IP 结账可以用支付宝和微信支付。

链接

  • 官网：https://www.wallpapermachine.app
  • GitHub：https://github.com/WallpaperMachine/WallpaperMachine

独立项目，与 Wallpaper Engine / Valve 无关；创意工坊壁纸的版权归原作者，App 不附带任何壁纸资源。
