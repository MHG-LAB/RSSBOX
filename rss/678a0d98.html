不写代码，30 分钟把 Ulanzi TC002 改成 AI 工作搭子


我同时开着 Claude Code、Codex 和 Kimi Code 干活，现在不用再挨个切窗口看它们做完没有。抬头看一眼桌上这台像素时钟就知道了：蓝灯在跑，绿灯完成，红灯出错。

我不会写代码。这些功能全是让 AI 写的，我只负责说清楚要什么，再看时钟告诉它哪里不对。

这些功能我自己摸索了两天，踩了一堆坑。我把坑都总结进了三段提示词里，你照着做，30 分钟就能做出来。手上只要有一个能写代码的 Agent 就行。

先看效果

案例一：滚动字幕

网页里输入一句英文，时钟上滚动显示。

案例二：AI Coding 工作台

屏幕分成三栏：CC 是 Claude Code，CX 是 Codex，KM 是 Kimi Code。每个字母下面的小方块就是状态灯，蓝色表示正在运行，绿色表示已完成，红色表示出错。

我在电脑上让 Agent 干活，抬头一看，状态灯就变蓝了：

案例三：像素宠物

把三个状态灯换成一只橙色小螃蟹。Agent 工作时它敲键盘，任务完成时它跳起来庆祝，出错时它趴下。

这台时钟本身

TC002 有一块 52×16 的 RGB 像素屏，一共 832 颗 LED。机身顶部是一个红色旋钮和一条快捷键。

这块屏能显示时间、一个数字、一句短英文，或者一个简单的像素图案。内容再多就放不下了。所以别把它当第二块屏幕，它适合显示你此刻最关心的那一件事。

我买它有两个原因：外观好看，而且支持自己开发。

白色机身、红色旋钮，放在桌上很好看。能自己开发，是因为官方开放了接口，还把接口文档放在了网上。可以理解成：电脑上的程序把内容发给时钟，时钟负责显示。

配网和原厂功能的设置都在官方软件 Ulanzi Studio 里完成：

价格和购买渠道

我是在淘宝买的。

买之前要知道的限制

  • 只能连 2.4GHz Wi-Fi。我第一次开机就看到了 Fail，就是没连上 Wi-Fi；
  • 文字只支持英文和数字，中文和 emoji 要做成图片才能显示；
  • 自定义效果离不开电脑，这一点放到文章最后细说。

自己改难不难？一点都不难

你不需要会写代码，只需要一个能直接在电脑上干活的 Agent。豆包、WorkBuddy、Kimi Code、Codex、Claude Code 都可以。它们能自己建文件、写代码、启动程序，还能直接给时钟发指令、看效果。

你要做的只有两件事：

  1. 把想要的效果说清楚；
  2. 抬头看时钟，告诉 Agent 哪里不对。

开发方法：开两个窗口

具体做什么功能、提示词怎么写，都不用你自己去想。你只要把诉求跟 Agent 讲清楚，然后开两个对话窗口：

窗口一这样开头就行：

我买了一台 Ulanzi TC002 像素时钟，想让它[你的想法，例如：显示我电脑上几个 AI Agent 的工作状态]。


我不会写代码，准备用另一个窗口里的 Agent 来开发。请你：


    

  1. 先阅读官方接口文档，判断这个想法能不能做到；
    2. 

  2. 按从简单到复杂，拆成几个可以逐个完成的案例；
    3. 

  3. 每个案例写一段可以直接发给开发 Agent 的提示词，写清功能、限制和怎么验收。
    4. 



官方接口文档：
https://github.com/UlanziTechnology/Ulanzi-U-Clock-TC002/blob/main/protocol/Ulanzi_TC002_protocol-http-mqtt_CN.md

拿到提示词，贴进窗口二，它就开始写代码。做完一个案例，回到窗口一说一句接下来做第二个，拿到新提示词，再贴回窗口二。

为什么不在一个窗口里做完？执行窗口里很快就会堆满报错、日志和改了又改的细节，这时候再在里面问下一步做什么，它会被前面的内容带偏。窗口一里只有目标和提示词，一直是干净的。

每个案例都是这五步：

① 窗口一：说想法，拿到提示词
        ↓
② 窗口二：贴提示词，Agent 读官方文档、写代码
        ↓
③ Agent 先自己测试，再发到真机上
        ↓
④ 你看时钟，说出哪里不对
        ↓
⑤ Agent 修改，你再看，直到满意

写代码几乎不花时间，大部分时间都在第 ④ 和第 ⑤ 步。

为什么我用 Kimi Code

两个窗口我都用的 Kimi Code，理由有两个：代码能力比较强，价格低。

代码能力强，还会自己用网页。 Kimi Code 自带浏览器，写完网页后会自己打开、自己点按钮检查效果。左边是对话，右边就是它正在测试的网页：

这次好几个问题，我只说了看到的现象，原因都是它自己找到的：

  • 我说字没有滚动，它查出是设备自带的滚动参数不生效，改成由程序控制文字移动；
  • 我说屏幕上少了像素点，它查出是设备显示 GIF 时出了问题，改成逐帧发送图片；
  • 我说动画一直停在同一个姿势，它查出是同一个状态被反复推送，动画每次都从头开始。

这些我都不会，也不需要会。

价格低，对开发很重要。 开发不是问一次就完，三个案例我在执行窗口里来回改了三十多轮，每一轮它都要读代码、改代码、在真机上测试。我用的是 200 元一个月的会员，两天的开发都在 Kimi Code 里完成。

如果你手上已经有其他 Agent，直接用就行，后面的方法和提示词完全一样。

开始之前：三件准备

  1. 用 Ulanzi Studio 给时钟配网，连 2.4GHz Wi-Fi；
  2. 电脑和时钟连同一个 Wi-Fi。电脑连手机热点、时钟连家里路由器，是连不上的；
  3. 记下时钟屏幕上滚动显示的 IP 地址。

这三步没做好，后面每个案例都会报连不上时钟，而且看报错很难想到是网络的问题。

下面三段提示词，是我把两天里踩过的坑提前写进去之后的最终版。直接复制给窗口二，三个案例加起来大约 30 分钟就能做完。

案例一：滚动字幕怎么做

请帮我做一个控制 Ulanzi TC002 像素时钟的网页小工具。我不会编程，请你直接创建、运行和调试，不要只给我代码。


功能：


    

  1. 支持连接我的 TC002；
    2. 

  2. 输入一句英文，选择文字颜色（给几种常用颜色，也可以自定义）；
    3. 

  3. 点击发送，短句在屏幕上水平、垂直居中，长句从右往左循环滚动；
    4. 

  4. 失败时用简单的话告诉我原因，例如 IP 填错、电脑和时钟不在同一个 Wi-Fi。
    5. 



请先阅读官方接口文档：
https://github.com/UlanziTechnology/Ulanzi-U-Clock-TC002/blob/main/protocol/Ulanzi_TC002_protocol-http-mqtt_CN.md


注意：


    

  1. 文字接口只支持英文和数字；
    2. 

  2. 推送内容后，还要切换到对应页面，屏幕才会显示；
    3. 

  3. 设备自带的滚动参数可能不生效，请由程序自己控制文字移动；
    4. 

  4. 不刷机，不用 MQTT，不装复杂框架；浏览器不能直接连设备时，用本地程序中转。
    5. 



完成后启动网页，在我的时钟上实际发送一次，再一步一步教我使用。

这个案例的坑：

  • 网页说发送成功，时钟没变化：只推送了内容，没切换到对应页面；
  • 字不滚动：设备自带的滚动参数没用，要让程序自己控制文字移动。

两条都已经写进上面的提示词了。还有一条要记住：Agent 说成功不算数，抬头看时钟才算。

案例二：AI Coding 工作台怎么做

请在刚才的 TC002 项目网页里，增加一个“AI Coding 工作台”tab。保留滚动字幕功能，不要重做项目。我不会编程，请你直接创建、运行、测试和修复。


功能：


    

  1. 网页显示 Codex、Claude Code、Kimi Code 三张卡片，状态分为排队中、运行中、已完成、出错了；
    2. 

  2. 时钟屏幕分三栏，白色字母 CC、CX、KM，每个字母下方中间放一个小方块，用颜色表示状态：排队黄、运行蓝、完成绿、出错红；
    3. 

  3. 我平时直接在客户端和终端里使用这三个工具，请让这些任务的状态也能同步到时钟。
    4. 



实现要求：


    

  1. 先用本地测试任务验证三个状态可以同时变化、互不覆盖，再接真实工具；
    2. 

  2. 优先使用各工具官方的事件钩子或本地会话记录判断状态，不要凭“软件开着”就当作在工作；
    3. 

  3. 判断完成时，除了程序有没有报错，还要确认任务真的有结果；
    4. 

  4. 只有状态变化时才更新时钟，不要重复推送；
    5. 

  5. 修改工具配置前先备份；
    6. 

  6. 某个工具接不上，就明确告诉我原因，不要假装已经支持。
    7. 



完成后启动网页，分别用三个工具跑一个小任务，告诉我哪些已经跑通、哪些还没有。

这个案例的坑：

  • 别用 logo 当图标：我最开始让它把三个 logo 转成像素图标，16×16 的格子里大小不一、颜色乱。最后还是字母加状态灯最清楚；
  • 显示完成，其实没做：程序没报错，不代表任务真的做完了，所以提示词里要求它检查结果；
  • Codex 要先信任钩子：在 Codex 的设置里审核并信任。我信任之后仍没收到状态，到写这篇文章时 Codex 还没跑通，Claude Code 和 Kimi Code 都已经跑通。

案例三：像素宠物怎么做

请在刚才的 TC002 项目里增加一个“像素宠物”tab。保留滚动字幕和工作台，不要重做项目。我不会编程，请你直接创建、运行、测试和修复。


宠物根据真实任务状态显示四种动画：


    

  1. 没有任务：睡觉、眨眼；
    2. 

  2. 有 Agent 在运行：敲键盘；
    3. 

  3. 全部完成：蹲下再跳起庆祝；
    4. 

  4. 任意任务出错：晃一下趴下，旁边闪感叹号。
    优先级：出错 > 运行 > 完成 > 空闲。
    5. 



形象要求：


    

  1. 画面 52×16，黑色背景，只用一种主色，外形卡通、轮廓简单，不要高光、阴影和多余色块；
    2. 

  2. 我会发参考图给你，按参考图的风格设计；
    3. 

  3. 每种状态 4～6 帧，动作要有变化；
    4. 

  4. 素材单独放在一个文件夹，方便以后替换。
    5. 



实现要求：


    

  1. 不要用 GIF，请用官方的位图绘制指令逐帧发送；
    2. 

  2. 只在状态真正变化时切换动画，同一状态重复出现时不要从头重播；
    3. 

  3. 只在第一次进入时切换页面，之后只更新画面；
    4. 

  4. 动画必须由真实任务状态驱动，不要循环播放来假装工作；
    5. 

  5. 网页可以切换“文字状态”和“像素宠物”两种模式；
    6. 

  6. 加一组标明“调试”的按钮，方便测试四种动画，调试不影响真实任务记录。
    7. 



完成后先用调试按钮检查四种动画，再用一个真实 Agent 任务验证联动。

宠物怎么设计才好看

52×16 的屏幕很小，形象按这三条来：

  1. 颜色少：黑底加一种主色就够了。颜色一多，放到屏幕上就糊成一片；
  2. 外形卡通、简单：轮廓一眼能认出来，细节越少越好；
  3. 动作多一点：外形简单，就靠动作出效果。每个状态做 4～6 帧，比如空闲时左右看，工作时歪头敲键盘，完成时先蹲下再跳起。

这个案例的坑

  • 动画一直停在同一个姿势：Agent 工作时会连续发出同样的状态，程序每次都重新推送，动画就一直从第一帧开始；
  • 屏幕上缺了像素点：源图是实心色块，用 GIF 发到时钟上却缺了一块块，改成逐帧发送图片才解决。

两个问题都已经写进上面的提示词。

遇到问题时，怎么跟 Agent 说

就算提示词写得再完整，第 ④ 步还是会遇到问题。下面这几种说法最好用：

用之前要知道：它离不开电脑

最后有一件事必须说清楚：这些效果都依赖电脑上的程序一直开着。

滚动字幕、宠物动画、Agent 状态，全是电脑上的程序一帧一帧推给时钟的。电脑关机、合盖休眠，或者程序被关掉，时钟就不会再更新。

时钟断电重启后，自定义页面会全部消失，回到原厂界面，需要程序重新推送一次。

想让它长期这样工作，做两件事：

  1. 把电脑上的程序设成开机自动启动；
  2. 在路由器里给时钟固定 IP。不然哪天路由器重新分配地址，程序就找不到它了。

这两件事同样可以直接交给窗口二去做。

这台设备适合谁

如果你想显示大量中文，或者希望自定义效果脱离电脑独立运行，它不适合你。

如果你在用 AI Coding，又喜欢桌搭，它很值得折腾。代码 Agent 会写，你要做的是说清楚想要什么，然后抬头确认它是不是真的做到了。

这两天里，Agent 好几次告诉我已经成功了：滚动设好了，任务跑完了，动画在播了。每一次都是我抬头看了一眼时钟，才发现不是那么回事。

现在，三个任务都完成了。小螃蟹停下敲键盘，蹲下，跳起来，给我放了一场只有 832 颗像素的烟花。
